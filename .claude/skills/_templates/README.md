# Skill Templates

存放改造 skill 用的模板与示例。

## 内容

- `IPD-SKILL-DISCO-TEMPLATE.md`：把单文件 SKILL.md 改造为 DisCo 形态的标准模板
- `example/db-migration/`：用 db-migration 套模板做的示范产出（验证模板不出错）

## 何时用

当你需要把一个单文件 SKILL.md 升级为 DisCo 形态时：

1. 读 `IPD-SKILL-DISCO-TEMPLATE.md` 了解步骤
2. 看 `example/db-migration/` 实际产出
3. 套到自己 skill 上

## 已示范的改造样本

- `.claude/skills/gen-test/` —— DisCo 形态完整样板（51 行 SKILL.md + 5 篇 references/ + 4 个 scripts/ + 3 个 examples/）

## 不在本目录范围

- 项目级 CLAUDE.md / AGENTS.md 改动
- ai-native-sdlc 链接的 skill 改动（已有完整 references/）
