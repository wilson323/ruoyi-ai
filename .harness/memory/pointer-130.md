> **类型**：反思层
> **创建时间**：2026-09-20

## Why（为何需要）
R129 写"5 根因"但每个根因的"为什么反复"又穿透 3 层 = 反思链深度 = 15。R131 拍板机制要求深度 > 3 必须升格为反脆弱指针，否则下次同类问题会再次穿透（治标不治本）。

## How（如何触发）
```bash
bash .harness/evolve/loop.sh --reflect-depth-audit
# 输出每根因的"为什么反复"穿透层数，>3 自动写入 pointer-候选
```
