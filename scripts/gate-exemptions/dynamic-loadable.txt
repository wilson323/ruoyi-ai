# scripts/gate-exemptions/dynamic-loadable.txt
# check-dynamic-loadable.sh 的显式豁免清单
#
# 格式（每行一条豁免项，理由不可为空）：
#   <后端 component 字段>  # 理由
#
# 硬约定（不许放宽）：
#   1. 理由为空的行会被门禁拒绝执行（exit 2）。没审过的项不许静默通过。
#   2. 本文件不存在 = 无任何豁免，全量照常报红。
#      不是「全部豁免」，也不是「静默通过」。
#   3. 本文件之外的项照常判红，DIFFS>0 → exit 1 判定条件原样保留。
#   4. 豁免项对应的视图若已不存在，判「豁免项失效」并 exit 1 —— 必须回来删行。
#      清单只增不减的话，最后会变成一张掩盖一切的废纸。
#
# 登记标准：必须是「真实存在、正在被后端菜单 component 字段动态加载」的视图，
#          即静态扫描看不见、但运行时可达的页面。确认它不是死代码即可登记。
#          真死代码（后端已不下发该 component）不进本文件，直接删页面。

# 角色权限配置页：后台菜单动态加载的现役页面，静态路由表里看不到但运行时可达，
# 删掉会导致权限配置入口点开白屏。2026-10-03 人工确认为在用页面，非死代码。

# 2026-10-03 人工确认为在用页面，非死代码。
