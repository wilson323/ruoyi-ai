# C03 目标客户与细分市场定义

## 目标

产出**目标客户画像**（交付物要求：深管阻断），供 C08 基准与 GTM 首批客户锚定。

## 输入

C01 痛点证据摘要、候选行业/区域、决策角色与预算线索。仅本项目资料 + 用户输入。

## 步骤

1. 检索「客群」「细分」「画像」「ICP」；无候选细分则请用户补充，不擅自发明行业名单。
2. 按可区分维度（行业/规模/区域/场景/决策链）列出**有依据**的细分；有几个写几个，不凑 3–5 个。
3. 对每个采纳细分给出：关键特征、主 JTBD、痛点、成功标准、与本产品契合点；每条附来源。
4. 若用户指定首发滩头细分，按「痛点紧迫度 / 付费意愿证据 / 可赢份额线索 / 转介可能」四项整理对比表；证据不足标「未取得」。
5. 输出「资料核对 / 细分表 / 画像 / 滩头建议（推断须标注）/ 缺项清单」。

## 禁止事项

- 禁止编造人口统计或公司名单凑画像。
- 禁止把「建议默认 3 个 persona」当作必须输出个数。
- 禁止给出 Gate 签署结论。
