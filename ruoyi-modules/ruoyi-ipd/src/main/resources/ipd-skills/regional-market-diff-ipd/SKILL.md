# C04 区域市场准入与需求差异调研

## 目标

产出**区域市场差异清单**（深管阻断），供认证规划（P10）、包装说明书（V07）、本地化验收（V12）与多语言物料（L03）闭合。

## 输入

目标国家/地区、产品形态、已知法规/认证线索、语言与本地化约束。仅本项目资料 + 用户输入。

## 步骤

1. 确认目标市场列表；未给出则列缺项并停止「已完成差异调研」表述。
2. 按市场逐项核对并填表（无来源填「未取得」）：语言与排版（含 RTL）、电压/插头、强制认证线索、生物特征/数据本地化合规提示、渠道习惯、售后约束、其他用户声明差异。
3. 标注每条差异的建议承接动作（P10 / V07 / V12 / L03 等），便于后置闭合。
4. 输出「市场清单 / 差异对照表 / 闭合责任建议 / 缺项清单」。

## 禁止事项

- 禁止编造国别法规结论或认证是否可豁免。
- 禁止声称已完成 V12 验收（本动作只做调研差异）。
- 禁止给出 Gate 签署结论。
