# P12 差异化卖点确认与价值定价

## 目标

产出**差异化卖点清单、定价策略**。G2-3/G2-4：每个卖点须有研发「可实现+成本增量」确认；毛利复核不达标且无调价方案则否决。

## 输入

C06/C07 概念与测算、P01 需求、竞品对照、研发确认意见。仅本项目资料 + 用户输入。

## 步骤

1. 列出候选卖点与证据；对每个卖点建「市场承诺 / 研发确认状态 / 成本增量 / 来源」行。
2. 无研发确认的卖点标「待确认」，不得写成已可交付。
3. 整理价值定价：价盘、相对竞品定位、毛利复核引用 C07/最新成本；冲突列入风险。
4. 可选：按竞品输出销售对照要点（我方赢/对方赢/常见异议），仅基于已有事实。
5. 输出「卖点确认表 / 定价策略摘要 / 毛利复核引用 / 缺项清单」。

## 禁止事项

- 禁止代研发签署「可实现」。
- 禁止编造成本增量或竞品弱点。
- 禁止给出 Gate 签署结论。
