# V07 包装、说明书、快速指南定稿

## 目标

产出**包装设计稿、用户手册**等定稿清单（深管阻断），并与 C04 差异、V12 本地化验收闭合。

## 输入

C04 差异清单、语言/合规要求、包装与说明书草案、版本号。仅本项目资料 + 用户输入。

## 步骤

1. 列出必交付物料：包装、说明书、快速指南；用户声明的其他物料一并列入。
2. 对照 C04：语言（含 RTL）、合规警示、电压/插头图示等是否落入文稿；未落实项入缺项。
3. 每项登记：定稿状态、版本/日期、责任人、来源文件标题。
4. 输出「物料定稿表 / 与 C04 对照 / 缺项清单」。未定稿不得宣称 G4-6 本地化已满足。

## 禁止事项

- 禁止编造已定稿或已印刷完成。
- 禁止用中文稿冒充已完成多语言定稿（除非用户证明目标市场仅中文）。
- 禁止给出 Gate 签署结论。
