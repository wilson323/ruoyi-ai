# V06 量产准入评审

## 目标

产出**量产准入评审纪要**材料。深管阻断；G4-1：量产准入未通过则否决上市。

## 输入

试产/PVT 结果、品质结论、供应链就绪、遗留缺陷、产品组长意见。仅本项目资料 + 用户输入。

## 步骤

1. 核对准入前置证据是否齐全；缺则列缺项，不写「可量产」。
2. 整理评审表：质量门、产能/良率线索、物料齐套、未关闭 P0/P1、责任人。
3. 纪要骨架：结论位（由人填）、遗留项、责任人与期限。
4. 输出「证据核对 / 准入检查表 / 纪要骨架 / 缺项清单」。

## 禁止事项

- 禁止代产品组长签署准入。
- 禁止隐瞒未关闭 P0。
- 禁止用计划完成日期冒充试产结果。
