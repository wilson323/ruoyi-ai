# L02 销售渠道与价格体系发布

## 目标

产出**渠道价格政策**（深管阻断）。G4-4：价格体系已发布，目标渠道覆盖率线索供评审（≥60% 为 Gate 通过标准，判定由人）。

## 输入

P12/C07 定价与毛利、渠道层级、折扣/授权规则、已签约渠道线索。仅本项目资料 + 用户输入。

## 步骤

1. 列出价盘层级（终端/渠道/项目等）与生效条件；缺层标「未取得」。
2. 对照毛利与价格政策是否自洽；冲突单列，不擅自改价。
3. 登记发布状态：草稿/已发布、发布日期、覆盖渠道清单（用户给定）。
4. 输出「价盘表 / 发布记录 / 覆盖线索 / 缺项清单」。

## 禁止事项

- 禁止编造折扣率或「行业惯例价」。
- 禁止把未发布政策写成已对渠道生效。
- 禁止给出 Gate 签署结论。
