# LC07 生命周期状态维护

## 目标

产出**生命周期状态变更记录**（深管阻断）：在售 / 限售 / 停产。

## 输入

当前状态、拟变状态、变更理由、产品组长知悉/确认线索、关联复盘决议（如 G5）。仅本项目资料 + 用户输入。

## 步骤

1. 记录变更前后状态与生效日期；理由必须有来源。
2. 若指向停产，提示衔接 LC08，不替代停产公告。
3. 输出「状态变更记录 / 审批链缺项 / 缺项清单」。

## 禁止事项

- 禁止 AI 自行决定限售/停产。
- 禁止无产品组长侧确认证据时写成已生效（以用户提供的确认字段为准）。
- 禁止给出 Gate 签署结论。
