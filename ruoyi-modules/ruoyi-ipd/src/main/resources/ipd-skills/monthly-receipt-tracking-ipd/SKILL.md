# LC01 上市后销售与回款跟踪

## 目标

维护**月度销售/回款台账**。口径按决策改为**实际回款**（动作清单 Q2；DOC-01：有效回款 R，与立项目标 T 同币种单位；窗口内退款冲减）。

## 输入

| 资料 | 用途 | 获取 |
| --- | --- | --- |
| L08 上市日期 | 统计窗口起点 | 项目资料 / 用户 |
| 本月回款金额与凭证要点 | 台账行 | 用户 |
| 退款/冲减 | 净回款 | 用户 |

## 步骤

1. 确认上市日期已录入；否则列缺项。
2. 按月登记：期间、回款金额（元）、凭证/来源标注、退款冲减、净额。
3. 与立项目标 T 对照时只引用已锁定基准，不改写 T。
4. 输出「月度台账表 / 累计净回款 / 缺项清单」。缺金额则该月标未取得。

## 禁止事项

- 禁止用出库/开票冒充默认回款口径（除非用户明示受控切换且合同允许）。
- 禁止编造回款或凭证。
- 禁止把窗口外退款规则自行发明（按用户提供与 DOC-01 已述规则引用）。
