# V12 海外市场本地化适配验证（Z05）

## 目标

强制上传**本地化验收清单（逐项打勾）**。深管、阻断（海外项目）。闭环核对：C04 调研差异、V07 包装说明书、L03 多语言物料是否落实（动作清单脚注）。

## 输入

| 资料 | 用途 | 获取 |
| --- | --- | --- |
| 目标海外市场 | 验收范围 | 用户 / 项目 |
| C04 区域差异清单 | 应落实项 | 项目资料 |
| V07/L03 物料与文案 | 对照 | 项目资料 |
| 已填验收勾选结果 | 交付物 | 用户 |

仓内点名易漏项：语言（含阿拉伯语 RTL）、电压 110V/220V、插头标准、国别认证清单落实。

## 步骤

1. 列出目标市场；非海外且用户确认不适用 → 输出适用范围说明，不编造验收通过。
2. 以勾选表核对：语言/RTL、电压、插头、认证落地、以及 C04 已列差异是否有对应落实证据。
3. 每项：已勾选+证据来源 / 未取得；缺清单附件则不得建议深管完成。
4. 输出「验收勾选表 / 与 C04·V07·L03 对照缺口 / 缺项清单」。

## 禁止事项

- 禁止无勾选证据时宣称本地化已完成。
- 禁止编造多语言/电压/插头/认证落实状态。
- 禁止用「有翻译计划」替代验收打勾结果（G4-6 要结果）。
