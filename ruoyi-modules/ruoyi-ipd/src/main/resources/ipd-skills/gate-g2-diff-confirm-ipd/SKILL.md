# P13 差异化确认评审会（G2）

## 目标

为 **G2 差异化确认** 备料。前置：P01/P02/P12 完成。G2 后进入需求基线冻结，此后变更走 D06（Gate 要素 + DOC-05）。

## 输入

PRD、版本规划、差异化卖点与定价、P08 里程碑日期、P10 认证规划清单。仅本项目资料 + 用户输入。

## 步骤

1. 核对 P01/P02/P12 交付物是否可追溯；缺则列缺项。
2. 按 G2 六项整理证据（判定由人）：
   - G2-1 PRD 完整性（未上传否决）
   - G2-2 需求优先级与版本规划
   - G2-3 卖点可交付性（不可实现否决）
   - G2-4 价值定价与毛利复核（低于门槛且无调价方案否决）
   - G2-5 技术方案与里程碑（**关键里程碑日期缺失否决**）
   - G2-6 认证清单：**DOC-05** — 清单/周期未完**可过 G2**，须保留缺口跟踪；**不得伪标已取得认证**
3. 强制输出物：评审材料、要素判定表、会议纪要。
4. 提醒：P08 日期支撑上市准时率/窗口命中率 KPI 取数。

## 禁止事项

- 禁止代签或伪造纪要。
- 禁止将 P10 规划状态写成认证已通过。
- 禁止建议跳过里程碑日期登记。
