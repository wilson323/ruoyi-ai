# C02 竞品分析

## 目标

产出**竞品分析报告**，支撑 G1-3（≥3 家对比、≥2 项差异点线索——判定由人）。深管阻断。

## 输入

本产品定位与客群、候选竞品名单、功能/价格/渠道/技术资料。仅本项目资料 + 用户输入；不联网。

## 步骤

1. 检索「竞品」「价格」「渠道」「技术方案」；无竞品名单则停止比较，只出缺项。
2. **目的裁剪**（用户声明时）：产品设计侧重功能矩阵；战略侧重格局与壁垒线索；融资材料侧重差异一页纸。未声明则四维齐全、篇幅克制。
3. 对每个竞品填四维：功能、价格（币种/时间）、渠道、技术路线；每格附来源。
4. **可信度**：公开规格/报价页摘录=高；转述无出处=低（不得当已验证事实）。标注信息时效（资料中的日期）。
5. 差异化机会仅基于有来源事实；推断标「推断」。可选：追平/差异/创新三层建议，须挂证据行。
6. 输出「资料核对 / 对比表 / 差异机会 / 冲突与待确认 / 缺项清单」。不凑默认「5 家」。

## 禁止事项

- 禁止编造竞品名、价格、渠道、专利或客户。
- 禁止声称已联网或把模型常识当来源。
- 禁止给出 Gate 签署结论。

依据：QoderWork「竞品分析」（目的模板/可信度，改写）；上游 competitor-analysis；六阶段 C02；五大 Gate G1-3。
