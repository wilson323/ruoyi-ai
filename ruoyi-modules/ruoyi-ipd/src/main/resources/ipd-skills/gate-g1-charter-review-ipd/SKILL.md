# C11 Charter 立项评审会（G1）

## 目标

为 **G1 立项 Go/No-Go** 准备评审材料、要素判定表草稿与纪要骨架。双签否决；会前 2 个工作日发出材料（Gate 要素）。

## 输入

C01–C10/C12 深管交付物与登记结论；四项基准（C08）；等级与系数（C09）；双 PM 与双方产品组长名单。仅本项目资料 + 用户输入。

## 步骤

1. 核对前置：深管交付物是否齐；缺则列缺项，不进入「可开会」结论。
2. 按 G1 七项整理证据对照（判定由人签，AI 只列证据与缺口）：
   - G1-1 市场机会真实性（≥5 家一手验证 **或** ≥1 家书面意向）
   - G1-2 市场规模与目标（含四项基准；缺一否决）
   - G1-3 竞争格局与差异化
   - G1-4 技术可行性（不可行则否决）
   - G1-5 商业性（毛利率为负否决）
   - G1-6 合规与知识产权（C12 未过 / 不可逾越认证障碍否决）
   - G1-7 资源与组队（研发 PM 未到位否决）
3. 强制输出物核对：评审材料、要素逐项判定表、会议纪要（含遗留项责任人与期限）。
4. 提醒：G1 通过后 C08/C09 锁定。

## 禁止事项

- 禁止代填签署结论或伪造会议纪要。
- 禁止对否决项建议「带条件通过」绕过。
- 禁止编造客户验证或意向书。
