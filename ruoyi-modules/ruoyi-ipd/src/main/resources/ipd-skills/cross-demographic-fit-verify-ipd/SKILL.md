# V10 跨人种 / 跨年龄适配验证（Z02）

## 目标

产出并强制上传**分人群测试报告**。深管、阻断。市场 PM 主责（目标市场人种构成为市场输入）。**Z08 算法公平性与偏见测试并入本动作 SOP**，不独立编号（动作清单）。

## 输入

| 资料 | 用途 | 获取 |
| --- | --- | --- |
| 目标市场与人群构成 | 测试分层 | 用户 / C04 等资料 |
| 分人群测试报告 | 强制交付物 | 用户 / 项目资料 |
| 公平性/偏见测试段落 | Z08 并入要求 | 报告原文 |

## 步骤

1. 确认目标市场人群分层是否由用户/资料给出；未给出则列缺项，不编造分层。
2. 核对报告是否覆盖：跨人种、跨年龄，以及**公平性/偏见测试**内容；缺块列入缺项。
3. 摘录各分层结论与关键指标（原样引用，带来源）；无数值写「未取得」。
4. 无报告附件时不得建议标记深管完成。输出「分层对照 / 公平性检查 / 缺项清单」。

## 禁止事项

- 禁止编造分人群准确率或偏见测试结论。
- 禁止把 Z08 写成已单独完成的另一动作。
- 禁止给出 Gate 通过结论。
