# C06 产品概念与差异化定位

## 目标

产出**产品概念说明书**，对齐 G1-3「竞争格局与差异化」（差异点≥2 且难在 6 个月内被复制——判定由人）。

## 输入

C01–C04/C02 结论摘要、目标客群、候选卖点与竞品对照。仅本项目资料 + 用户输入。

## 步骤

1. 检索概念/定位/卖点相关材料；汇总「为谁、解决何问题、如何做、相对替代方案」。
2. 按 JTBD 六要素整理价值主张草稿：Who / Why / 现状 / How / 之后 / Alternatives；缺项标「未取得」。
3. 列出拟议差异点≥2 的证据：对照竞品事实、可防御理由、研发可实现性线索（无研发确认则标待确认）。
4. 输出「概念一页纸 / 价值主张表 / 差异点证据表 / 缺项清单」。差异点不足或无证据时不得宣称定位已定稿。

## 禁止事项

- 禁止编造竞品无法复制的「壁垒」话术。
- 禁止把营销口号当已验证差异。
- 禁止给出 Gate 签署结论。
