# LC04 双 PM 贡献度评定

## 目标

产出**贡献度评定表**。三方评定 = 双 PM + 各自产品组长；**A 角 = 产品组长**（动作清单 A5）。市场占比 **40–65%**、研发 **35–60%**（动作清单）。

## 输入

| 资料 | 用途 | 获取 |
| --- | --- | --- |
| 双 PM 自评与互评要点 | 五维度素材 | 用户 |
| 产品组长确认意见 | A 角 | 用户 |
| 拟议市场/研发占比 | 校验区间 | 用户 |

「五维度」名称以用户或项目已有评定表字段为准；仓内清单未逐条展开维度名时，**不得编造维度清单**，只校验已给字段与占比区间。

## 步骤

1. 收集已有评分/维度行；无表则列缺项并请用户提供模板字段。
2. 校验市场%、研发% 落在 40–65 / 35–60；且二者与用户声明规则一致（不擅自重归一）。
3. 记录确认链：双 PM → 产品组长。
4. 输出「评定表摘录 / 占比校验 / 缺项清单」。

## 禁止事项

- 禁止 AI 代定贡献度百分比或伪造组长确认。
- 禁止发明未在输入中出现的五维度名称冒充制度原文。
- 禁止把两 PM 分数平均成单一奖金系数（DOC-01 相关约束：各自评定）。
