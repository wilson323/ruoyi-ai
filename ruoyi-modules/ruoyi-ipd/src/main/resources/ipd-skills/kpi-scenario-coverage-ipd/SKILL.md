# K04 场景覆盖率归集

## 目标

上市后 **6 个月末**归集场景覆盖率。数据来源：销售报备 + 交付验收记录；分母为 C08 场景数目标。

## 输入

C08 场景数目标、已落地场景清单与验收/报备证据、L08 上市日期。仅本项目资料 + 用户输入。

## 步骤

1. 确认窗口末日与场景数目标；缺则列缺项。
2. 逐条登记已覆盖场景及证据类型（报备/验收）；无证据不计入。
3. 覆盖率 = 有效场景数÷目标；展示算式。
4. 输出「窗口核对 / 场景明细 / 覆盖率 / 缺项清单」。

## 禁止事项

- 禁止把意向场景计入已覆盖。
- 禁止编造验收记录。
- 禁止改写锁定的场景数目标。
