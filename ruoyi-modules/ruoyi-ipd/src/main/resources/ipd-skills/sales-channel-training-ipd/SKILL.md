# L04 销售与渠道培训

## 目标

产出**培训材料、培训签到记录**核对（深管阻断）。G4-5：核心渠道培训覆盖率 ≥80%（判定由人，AI 只归集输入）。

## 输入

培训教材、场次、参训渠道/分支、签到表、覆盖率计算所需分母。仅本项目资料 + 用户输入。

## 步骤

1. 列出培训场次与对象（含海外分支是否覆盖）。
2. 归集签到/完成证据；无签到不得计为已训。
3. 若用户给出核心渠道总数与已训数，计算覆盖率并展示算式；缺数标「无法计算」。
4. 输出「场次表 / 覆盖计算 / 缺项清单」。

## 禁止事项

- 禁止伪造签到或覆盖率。
- 禁止把「已发送材料」等同「已完成培训」。
- 禁止给出 Gate 签署结论。
