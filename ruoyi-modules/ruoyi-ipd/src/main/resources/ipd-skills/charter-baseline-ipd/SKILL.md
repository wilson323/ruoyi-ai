# C08 销量预测与商业目标（四项基准）

## 目标

产出商业计划书 Charter 所需的**立项目标四项基准值**，作为后续奖金池与共担 KPI 的计算基准。G1 通过后锁定；修改须双签 + 审计（动作清单 + DOC-01）。

## 输入

| 资料 | 用途 | 获取 |
| --- | --- | --- |
| 目标客户与客单价/渗透假设 | 自下而上推导销售额 | 项目资料 / 用户 |
| 可比产品或渠道计划 | 对标或渠道数目标 | 项目资料 / 用户 |
| NPS/场景覆盖目标草案 | 四项中的 NPS、场景数 | 用户优先 |
| 既有 C01–C07 结论摘要 | 校验口径一致 | 项目资料检索 |

事实只来自 `project_knowledge_search` 本项目片段或本轮用户输入；未取得一律标「未取得」。

## 步骤

1. 检索并核对是否已有草案销售额、渠道数、NPS、场景数；记录来源标题。
2. **逐项录入四项基准**（缺一不可，空值不补 0）：
   - 上市后 6 个月**目标销售额**（人民币元，精确十进制）
   - **目标渠道数**
   - **NPS 目标**
   - **场景数目标**
3. 写明销售额推导：客户数×客单×渗透率，或可比产品对标；引用原始数字与单位。
4. 输出「资料核对 / 四项基准表 / 推导说明 / 缺项清单」。基准不齐则停止，请用户补齐后再定稿。

## 禁止事项

- 禁止编造销售额、渠道数、NPS、场景数或推导参数。
- 禁止用实际回款替代立项目标基数 T；禁止把未提供的项填 0。
- 禁止在未获双签授权时改写已 G1 锁定的基准。
- 禁止给出 Gate 通过/不通过结论。
