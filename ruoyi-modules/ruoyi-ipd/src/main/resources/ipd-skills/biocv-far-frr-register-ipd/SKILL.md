# D11 BioCV 算法训练与评测（Z01）

## 目标

在轻管三字段之外，**必须登记实测 FAR（误识率）与 FRR（拒识率）** 两个数值，使算法结果可追溯、可横向对比（动作清单）。不强制训练报告附件。

## 输入

| 资料 | 用途 | 获取 |
| --- | --- | --- |
| 实测 FAR / FRR | 成对登记 | 用户（评测方） |
| 评测条件摘要（可选） | 注释口径 | 用户 / 项目资料 |
| 模态说明（指纹/人脸等） | 上下文 | 用户 |

仅登记用户或项目资料中的数值；工具检索不到实测值则「未取得」。

## 步骤

1. 向用户确认是否已有成对 FAR、FRR；缺一则拒绝视为可完成，列缺项。
2. 原样记录数值、单位/量纲说明（比例）、评测日期与来源标注。
3. 若用户只给单侧数值：明确提示须**成对**，不臆补另一侧。
4. 输出「资料核对 / FAR-FRR 登记表 / 缺项清单」。可在备注中引用评测条件原文，不扩展训练方法论。

## 禁止事项

- 禁止编造或估算 FAR/FRR。
- 禁止用行业「典型值」冒充本项目实测。
- 禁止声称已上传训练报告为完成条件（本动作轻管不强制附件）。
