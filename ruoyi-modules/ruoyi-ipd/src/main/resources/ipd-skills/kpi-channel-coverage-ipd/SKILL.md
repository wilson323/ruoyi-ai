# K02 渠道商覆盖达成率归集

## 目标

上市后 **6 个月末**由产品组长归集渠道覆盖达成率。数据来源：渠道签约台账 / CRM（动作清单）。窗口原点 = L08 上市日期。

## 输入

C08 目标渠道数、实际签约渠道清单与签约日期、L08 上市日期。仅本项目资料 + 用户输入。

## 步骤

1. 确认窗口末日（上市日 + 6 个自然月）与目标渠道数；缺则列缺项。
2. 统计窗口内有效签约数（以用户/台账为准，不估测）；列渠道与签约日来源。
3. 达成率 = 实际÷目标；写出算式。缺数不补 0。
4. 输出「窗口核对 / 签约明细 / 达成率 / 缺项清单」。

## 禁止事项

- 禁止编造签约渠道。
- 禁止用意向客户冒充已签约（除非用户明文定义并来源标注）。
- 禁止改写锁定的目标渠道数。
