# C10 知识产权与合规预检（含 FTO）

## 目标

整理并归档**知识产权检索报告（含专利 FTO 分析）**。深管、强制交付物；**不阻断**阶段跳转，以留痕 + 逾期提醒管理（动作清单）。

## 输入

| 资料 | 用途 | 获取 |
| --- | --- | --- |
| 产品技术要点 / 关键方案 | 检索范围 | 项目资料 / 用户 |
| 已有专利检索或 FTO 报告 | 结论来源 | 用户上传 / 项目资料 |
| 目标市场清单 | 合规准入关联提示 | 项目资料 / 用户 |

不联网检索专利库；工具与用户均未提供的检索结论视为「未取得」。

## 步骤

1. 检索本项目是否已有检索报告、FTO 结论、高风险专利标注。
2. 按报告原文摘录：检索范围、日期、机构/执行人、结论（无高风险 / 有条件 / 高风险）、需跟进项。
3. 若无报告全文：停止分析，输出缺项（须强制上传检索报告方可标记深管完成）。
4. 输出「资料核对 / 检索与 FTO 摘要（带来源）/ 风险与待确认 / 缺项清单」。不替代法务终裁。

## 禁止事项

- 禁止编造专利号、权利人、侵权判断或「已检索公开库」表述。
- 禁止因本动作非阻断而建议跳过上传检索报告。
- 禁止给出 Gate 或法律上的最终合规结论。
