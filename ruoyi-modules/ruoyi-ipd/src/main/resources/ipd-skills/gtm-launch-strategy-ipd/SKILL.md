# L01 GTM 上市策略

## 目标

产出**GTM 上市方案**（深管阻断）。G4-8：首批目标客户 ≥10 家且各有责任人。

## 输入

C03 客群、目标区域、渠道策略草案、节奏与窗口、候选首批客户、可选 ICP/滩头说明。仅本项目资料 + 用户输入。

## 步骤

1. **滩头与 ICP**：在用户/资料已有客群上收窄首发区域与理想客户特征；未给出则标「未取得」，不推销外部市场库。
2. **四要素骨架**：目标区域、渠道、节奏、首批客户；逐项标注来源。
3. **渠道动作**：仅基于已有选择登记（直销/代理/伙伴等）；不展开无关获客 SaaS 清单。
4. **信息与对战要点**（可选）：相对竞品的一句话定位与常见异议，须挂 C02/P12 事实行。
5. 首批客户表：客户、区域、责任人、状态；不足 10 家或缺责任人 → 缺项，不凑数。
6. 成功度量：引用 C08 四项基准与可观察过程指标；无数据不编造 KPI。
7. 输出「滩头/ICP 摘要 / GTM 四要素 / 客户责任表 / 度量引用 / 缺项清单」。

## 禁止事项

- 禁止编造首批客户或责任人凑满 10 家。
- 禁止用通用互联网获客话术替代 IPD 渠道事实。
- 禁止给出 Gate 签署结论。

依据：WorkBuddy/pm-skills gtm-strategy、beachhead-segment、ICP、gtm-motions（方法参照，不 vendor）；五大 Gate G4-8。
