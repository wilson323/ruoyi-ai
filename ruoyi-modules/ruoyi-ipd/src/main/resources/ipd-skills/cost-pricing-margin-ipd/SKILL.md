# C07 成本/定价/毛利初步测算

## 目标

产出**成本与定价测算表**，支撑 G1-5 商业性（毛利率为负否决；门槛可配置，AI 不代判是否达标）。

## 输入

BOM/成本草案、目标定价或渠道加价规则、产品线毛利门槛（若用户提供）、币种与单位。仅本项目资料 + 用户输入。

## 步骤

1. 收集成本项与定价假设；缺关键输入则只出缺项，不算「已测算完成」。
2. 列测算表：成本构成、建议价/价盘、毛利计算公式与结果；数字原样引用并注明单位/时间。
3. 若存在渠道价与终端价多层，分别列出并标明口径，避免混用。
4. 毛利为负或与用户给出的门槛冲突时，明示冲突与待确认项，不建议「带条件通过」绕过否决语义。
5. 输出「资料核对 / 测算表 / 假设清单 / 缺项清单」。

## 禁止事项

- 禁止编造 BOM、采购价或「行业平均毛利」。
- 禁止用出货价口径偷换回款相关后续指标。
- 禁止给出 Gate 签署结论。
