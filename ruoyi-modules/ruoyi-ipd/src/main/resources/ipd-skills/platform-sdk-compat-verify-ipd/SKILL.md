# V11 平台兼容性与 SDK/API 对接验证（Z04）

## 目标

登记**对接范围与通过结论**。默认轻管、非阻断；**解决方案模板自动转深管且阻断**（动作清单）。仓内示例范围：系统级方案、子系统与第三方集成（如门禁/考勤/访客/停车等集成场景）。

## 输入

| 资料 | 用途 | 获取 |
| --- | --- | --- |
| 项目模板（硬/软/方案） | 深度与阻断 | 用户 / 项目 |
| 对接对象与范围清单 | 验证边界 | 用户 / 项目资料 |
| 通过/失败结论与残留问题 | 登记 | 用户 |

## 步骤

1. 确认模板类型：方案类按深管要求检查结论交付；硬/软维持轻管三字段 + 对接结论登记。
2. 列出对接范围（平台/SDK/API/子系统）；无范围则停止并请用户补充。
3. 逐项登记：已测/未测、通过结论、阻塞项责任人；未测标「未取得」。
4. 输出「模板与深度说明 / 对接范围表 / 缺项清单」。

## 禁止事项

- 禁止在硬/软模板下伪造「已升级深管」或相反。
- 禁止编造对接通过结论。
- 禁止把未测项写成已通过。
