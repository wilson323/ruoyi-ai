# L03 销售工具包

## 目标

产出**销售工具包清单 + 物料**齐套核对（深管阻断）。G4-5：工具包齐备。

## 输入

卖点（P12）、多语言要求（C04/V12）、既有物料文件清单。仅本项目资料 + 用户输入。

## 步骤

1. 按类目核对：彩页、PPT、DEMO、视频、官网、多语言物料；用户增补类目可追加。
2. 每项登记：有/无、语言版本、版本号或链接标题、责任人。
3. 对照未闭合本地化项，列入工具包缺口。
4. **可选·DEMO/样机故事板**：若用户要求演示路径，只整理「场景→页面/镜头→卖点证据」清单，不启动通用网页生成运行时；抛开原型不得计入齐套。
5. 输出「工具包齐套表 / 本地化对照 / 缺项清单」。

## 禁止事项

- 禁止声称已生成实际不存在的物料。
- 禁止用单一语言冒充多语言齐套。
- 禁止给出 Gate 签署结论。

依据：prd-html / prototype（故事板边界，不新建运行时）；六阶段 L03；五大 Gate G4-5。
