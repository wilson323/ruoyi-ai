# LC09 项目归档（资料归档，转只读）

## 目标

产出**项目归档包**（深管阻断）。停产或生命周期决议关闭后，资料可审查、可导出，项目进入只读；禁止再编辑/新增/删除业务资料（BR-PROD-05）。

## 输入

| 资料 | 用途 | 获取 |
| --- | --- | --- |
| LC07/LC08 状态与停产决议 | 归档前置 | 项目资料 / 用户 |
| 各阶段交付物与 Gate 纪要 | 归档清单 | 项目资料检索 |
| 导出包或附件清单 | 齐套核对 | 用户 / 系统 |

R=系统自动；业务责任 A=产品组长。智能体只整理清单与缺项，不代改项目状态。

## 步骤

1. 核对前置：生命周期决议已形成；若决议为停产须有 LC08 材料线索；未决议则列缺项，不得宣称可归档。
2. 按「可审查文档集」骨架建清单（有则登记标题/版本/日期，无则「未取得」）：
   - 概念：调研/竞品/概念/Charter/合规
   - 计划：PRD/版本规划/卖点定价/认证清单/G2 纪要
   - 开发与验证：变更单、试用报告、认证结果、量产/本地化证据、G3/G4 纪要
   - 发布与生命周期：GTM/工具包/上市日期、回款台账、90 日复盘、终算与贡献度、状态变更
3. 标注只读生效条件：状态=已归档后仅查看与导出；列出仍开放写路径（若用户声明）为风险。
4. 输出「归档齐套表 / 缺项清单 / 只读确认要点」；缺关键 Gate 纪要或强制交付物时不得标「归档完成」。

## 禁止事项

- 禁止在缺停产/关闭决议时伪标已归档。
- 禁止编造未上传的交付物文件名冒充齐套。
- 禁止指导绕过只读继续改基线或推进阶段。
- 禁止把通用「代码仓文档化」当成归档包本体；无代码仓时仅结构化清单即可。

依据：六阶段清单 LC09；主 Prompt BR-PROD-05；§3 映射 shipping-artifacts（推断，归档=可审查文档集）；DOC-05（已归档评审不静默改值）。
