# C12 生物特征数据合规审查（Z03）

## 目标

产出**合规审查清单**并强制上传。法律红线：**S/A/B 全等级阻断**（动作清单）。涉及生物特征数据处理的项目须挂载本动作。

## 输入

| 资料 | 用途 | 获取 |
| --- | --- | --- |
| 是否处理生物特征 / 数据类型 | 适用范围 | 用户 / 项目标记 |
| 目标市场（含出境场景） | 法域勾稽 | 项目资料 / 用户 |
| 既有隐私/合规材料 | 证据 | 项目资料检索 |

仓内明确点名的约束（动作清单脚注）：GDPR 特殊类别数据；国内个保法；《人脸识别技术应用安全管理办法》；数据出境安全评估。

## 步骤

1. 确认项目是否涉及生物特征；不涉及则请用户说明后仅输出「适用范围：不适用」依据，不编造审查通过。
2. 对适用项目，按上列法规/办法**逐项勾稽**：适用与否、已有证据、缺口、责任人（市场 PM / 合规 / 法务）。
3. 汇总为合规审查清单表；任一项无证据填「未取得」并入缺项。
4. 无完整清单交付物时，不得建议标记完成（深管强制附件）。

## 禁止事项

- 禁止编造「已通过合规审查」或伪造证书/评估文号。
- 禁止建议 B 级项目跳过本动作。
- 禁止把模型常识当作已完成的法律评估。
- 禁止给出 Gate 签署结论。
