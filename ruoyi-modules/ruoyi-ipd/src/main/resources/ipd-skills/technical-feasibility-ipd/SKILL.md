# C05 技术可行性预研

## 目标

整理可行性分析、待验证假设、预研建议，不冒充已完成实验。该动作为轻管，合同只要求人工登记完成；生成辅助材料不能将动作变成已完成。

## 输入

技术假设、既有预研数据、性能边界与方案约束。仅当前项目权限内资料与用户输入；引用来源标题和原值。关键输入缺失先列缺项，不用无依据数字、年份、预算或结论填空。

## 步骤

1. 核对当前范围、资料版本与来源，区分已发生事实和拟议方案。
2. 依输入形成可行性分析、待验证假设、预研建议，不冒充已完成实验，每项建议说明依据；未有依据的量化值留空并列缺项。
3. 核对与已确认需求、已审核文档和项目边界的一致性，列出冲突与需人工确认的选择。
4. 输出清晰标题、正文、出处、未完成的实际工作和负责人需确认事项。

## 禁止事项

- 不编造已实施、已测试、已送检、已采购、已批准等事实。
- 不写动作完成状态、关键日期、预算、人员分工或权限，不代替真实负责人批准。
- 不调用其他项目或外部环境，不恢复已退役回款台账、奖金池与业绩窗口。

依据：现役六阶段标准动作清单 C05；轻管只登记完成的原合同。智能体产出辅助材料，不替代人工/外部实际工作。
