# D05 双周开发评审（G3）

## 目标

每两周产出**双周评审纪要**。G3 为过程健康检查：**不设否决、不阻断跳阶**（Gate + DOC-05）；连续 2 次 P0 未升级 → 升级双方产品组长。

## 输入

本双周计划与完成情况、场景走查结论、变更单统计、风险/阻塞、成本与认证进度、D11 FAR/FRR（若适用）。仅本项目资料 + 用户输入。

## 步骤

1. 汇总本双周事实来源；无输入则只出缺项。
2. 按 G3 五项记录（不做通过/不通过门禁）：
   - G3-1 进度与里程碑（偏差与追赶计划）
   - G3-2 场景完整度（市场 PM 主答：端到端场景）
   - G3-3 需求变更（累计变更率；预警线 12%，目标 ≤15%）
   - G3-4 技术风险与阻塞（P0 须有升级与责任人）
   - G3-5 成本与合规跟踪
3. 同步摘录 D11 已登记 FAR/FRR；未达标则登记追赶计划（有来源才写）。
4. 输出纪要骨架：要素表、偏差、变更统计、风险清单、升级触发检查。

## 禁止事项

- 禁止把 G3 写成准入否决或拦截止入验证（DOC-05）。
- 禁止编造进度、变更率或 P0 关闭状态。
- 禁止代填产品组长升级决议。
