# L08 正式上市发布（上市日期锚点）

## 目标

完成上市发布记录，并录入**上市日期**。该日期是 6 个月回款窗口、90 天复盘、共担 KPI 评估的起算原点（动作清单 Q6；DOC-01：`bonus.launchAnchor=L08_ACTION`，取录入上市日期，不取动作完成日）。

## 输入

| 资料 | 用途 | 获取 |
| --- | --- | --- |
| G4（L07）已通过证据 | 前置门禁 | 用户 / 项目资料 |
| 实际上市日期 | 锚点 | 用户 |
| 发布范围/渠道说明 | 发布记录 | 用户 |

## 步骤

1. 确认用户声明 G4 已通过；无证据则列缺项，不建议执行 L08。
2. 登记上市日期（日历日）与来源；与「动作完成日」区分，不得混用。
3. 输出发布记录摘要：日期、范围、备注；提醒锁定与双签更正规则。
4. 缺上市日期则视为未完成锚点录入。

## 禁止事项

- 禁止在 G4 未通过时建议录入上市日期。
- 禁止擅自改写已录入上市日期（须双签 + 审计）。
- 禁止用动作完成日冒充上市日期锚点。
