# C09 项目等级与差异化系数

## 目标

形成**项目等级评定记录**：等级 S/A/B + 差异化系数，经产品组长确认后入档。G1 通过后与 C08 基准一并锁定（动作清单 + Gate G1 特殊规则）。

## 输入

| 资料 | 用途 | 获取 |
| --- | --- | --- |
| 市场机会与商业目标摘要 | 支撑等级提议理由 | 项目资料 / 用户 |
| 双 PM 联合提议意见 | 等级与系数草案 | 用户 |
| 产品组长确认结果 | A 角确认 | 用户（系统外确认后录入） |

已定固定值（动作清单）：**S=1.5 / A=1.0 / B=0.8**。校验边界仍须落在制度区间内（Gate：S 1.5–2.0 / B 0.6–0.8；A=1.0）。

## 步骤

1. 核对用户是否给出拟议等级与系数；未给出则只列缺项，**不代填**。
2. 校验系数是否等于对应等级固定值，且落在校验区间；不符则标「校验失败」并请用户更正。
3. 记录：提议人（双 PM）、确认人（产品组长）、等级、系数、确认时间/依据。
4. 输出「资料核对 / 等级与系数表 / 确认链 / 缺项清单」。缺产品组长确认则不得宣称已完成评定。

## 禁止事项

- 禁止 AI 自行选定等级或代填差异化系数。
- 禁止使用与已定固定值不符的系数并声称合规。
- 禁止在无产品组长确认证据时写成「已确认」。
- 禁止给出 Gate 通过/不通过结论。
