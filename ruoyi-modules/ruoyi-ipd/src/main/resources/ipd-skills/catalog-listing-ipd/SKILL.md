# L06 系统上架

## 目标

产出**上架确认记录**（深管阻断）：ERP 编码、官网、电商、渠道门户等用户声明渠道。

## 输入

SKU/物料编码、各上架点状态与截图/单号、生效日期。仅本项目资料 + 用户输入。

## 步骤

1. 列出适用上架点；不适用项由用户声明并记录。
2. 每点登记：已上架/未上架、编码或 URL 标题、确认人、日期。
3. 未完成点入缺项；全部未证成时不得宣称可执行 L08。
4. 输出「上架确认表 / 缺项清单」。

## 禁止事项

- 禁止编造 ERP 编码或上架完成。
- 禁止用内部测试环境冒充生产上架。
- 禁止给出 Gate 签署结论。
