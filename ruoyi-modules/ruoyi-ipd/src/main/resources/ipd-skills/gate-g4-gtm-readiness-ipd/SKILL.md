# L07 GTM 就绪评审（G4）

## 目标

上市前最后一道门禁备料。**通过后才能执行 L08**。按实际验证/认证/本地化**结果**评审，不以 G2/P10 规划替代（Gate + DOC-05）。

## 输入

L01–L06 交付与登记、V02 证书结果、V03/V06、V07/V12、质量缺陷状态、首批客户名单。仅本项目资料 + 用户输入。

## 步骤

1. 核对 L01–L06 完成态；缺则列缺项。
2. 按 G4 八项列证据与缺口（判定由人）：
   - G4-1 产品就绪（V02 未过 / 量产准入未过否决）
   - G4-2 质量与缺陷（P0 未清零否决）
   - G4-3 供应与备货
   - G4-4 价格与渠道体系
   - G4-5 销售工具与培训
   - G4-6 本地化与合规落地（强制认证未取得或适用 Z05 未完成否决）
   - G4-7 售后与支持
   - G4-8 GTM 可执行性（首批客户名单等）
3. 强制输出物：评审材料、要素判定表、会议纪要。
4. 提醒：通过后系统侧将生成 LC02/LC03/K01–K04 待办（Gate 叙述）；L08 上市日期为后置指标原点。

## 禁止事项

- 禁止用计划态冒充 V02/Z05 结果。
- 禁止代签或建议跳过 G4 直接 L08。
- 禁止编造培训覆盖率、备货或客户名单。
