# V02 认证测试送检（结果登记）

## 目标

对目标市场认证项登记**证书编号 + 通过日期**（动作清单）。轻管不强制证书扫描件；保留阻断性语义；**DOC-05**：G4 按实际取得/通过结果评审，G2/P10 放行不能豁免。

## 输入

| 资料 | 用途 | 获取 |
| --- | --- | --- |
| P10 目标市场认证清单 | 应对齐的项 | 项目资料 |
| 证书编号、通过日期、对应市场 | 结果登记 | 用户 |
| 未通过/进行中说明 | 缺口 | 用户 |

## 步骤

1. 列出 P10 清单中强制项与当前结果状态。
2. 对「已通过」项：登记证书编号、通过日期、市场；缺编号或日期则标未完成。
3. 对未通过/未送检：如实登记，不得写已通过。
4. 输出「认证结果表 / 与 P10 差异 / 缺项清单」。提醒：上市前 G4-1/G4-6 核实际结果。

## 禁止事项

- 禁止用「清单已填」「有计划」「G2 已过」冒充证书已取得。
- 禁止编造证书编号或通过日期。
- 禁止扩大要求强制上传扫描件（合同未授权扩大附件规则）。
