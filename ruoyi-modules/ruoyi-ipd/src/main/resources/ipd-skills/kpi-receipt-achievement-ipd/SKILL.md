# K01 销量/出货量达成率归集

## 目标

产品组长**月度**归集达成率。Q2 口径：默认分子为**实际回款**（非出库冒充）；分母为 C08 锁定目标销售额 T。一期可手动录入+凭证。

## 输入

C08 目标销售额 T、本期实际回款及凭证线索、L08 上市日期、窗口内退款冲减说明。仅本项目资料 + 用户输入。

## 步骤

1. 确认统计期间与 T；T 未锁定/缺失则列缺项，不算达成率终值。
2. 归集回款金额（原样引用单位/币种）；记录凭证或台账来源标题。
3. 达成率 = 回款÷T；展示算式。退款冲减仅按用户/台账规则，不擅自估计。
4. 输出「期间核对 / 回款明细摘要 / 达成率 / 缺项清单」。

## 禁止事项

- 禁止用出库/发货金额默认替代回款（除非用户明示例外口径并留痕）。
- 禁止编造回款或改写 T。
- 禁止把缺证据写成 0 达成且宣称已终算。
