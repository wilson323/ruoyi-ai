# K01 销量/出货量达成率归集

## 目标

根据现役动作目录 K01，整理销量或出货数量的指标证据报告。产品组长确认指标口径与结果；智能体仅核算已有证据，不提交、评分或批准指标。

## 输入

当前项目已明确的统计期间、销量或出货量口径、同口径目标数量、实际数量与可回读来源。仅本项目授权资料与用户输入；原文未给数量目标时列缺项，不将销售金额转换成件数。

## 步骤

1. 核对统计期间、单位、产品范围、实际数量与目标数量的口径一致；区分销量与出货量，不把不同口径混算。
2. 引用每条原始数量、来源标题与期间；无原始数量不得编造。
3. 目标数量大于零且来源齐全时，达成率 = 实际数量 / 目标数量 × 100%；展示分子、分母、单位与算式。缺目标、目标为零或口径冲突时列缺项，不产出终值。
4. 输出「指标口径 / 原始数量证据 / 达成率核算 / 待产品组长确认事项」。

## 禁止事项

- 不读取或恢复已退役回款台账、奖金池、业绩窗口，不以回款金额冒充销量。
- 不编造目标、实际数量、退货冲减规则或确认意见。
- 不把缺证据写成零达成，不代替产品组长确认。

依据：现役 ActionCatalog K01「销量出货量达成率归集」；KPI 保留、回款台账与奖金池退役的既有业务决策。技能名称保留仅为动作绑定兼容，不再代表数据源。
