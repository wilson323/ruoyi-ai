# LC02 上市后 90 天复盘（G5）

## 目标

上市日期 +90 天复盘备料。**双签否决**；**不终算奖金**（LC03）。G5-1 默认 25% 预警非否决（Gate + DOC-05）。

## 输入

LC01 回款台账、渠道/场景实际、客诉与 NPS、需求变更率、上市偏差、成本毛利、拟议生命周期决议。仅本项目资料 + 用户输入。

## 步骤

1. 核对 L08 上市日期与 +90 天时点；缺数据列缺项。
2. **指标健康度**：对有分子分母的指标算达成/偏差；缺分母不得填 0。异动先列同期产品/运营/故障上下文（用户提供），再写归因假设并标「推断」。
3. 按 G5 七项列证据：
   - G5-1 销售达成（90 日回款÷立项目标；低于预警线要原因与改进计划）
   - G5-2 渠道与场景覆盖
   - G5-3 客户反馈与质量（P0 未闭环否决）
   - G5-4 需求准确率复盘
   - G5-5 上市准时性与窗口命中
   - G5-6 利润与成本复盘
   - G5-7 迭代与生命周期决议（无决议否决；停产才生成 LC08）
4. 强制输出物：复盘报告、判定表、会议纪要要点。
5. 明确：本 Gate 不产出奖金终算。

## 禁止事项

- 禁止用 90 日预警自动写停产或取消奖金。
- 禁止代签双签；禁止编造回款达成率。

依据：QoderWork「产品指标复盘」（健康度/归因，改写）；五大 Gate G5；DOC-05。
