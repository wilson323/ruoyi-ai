# LC05 客户反馈与质量问题处理

## 目标

产出**问题处理记录**。深管非阻断（留痕 + 逾期提醒）。支撑 G5-3。

## 输入

客诉/反馈原文、缺陷等级、处理过程、闭环证据、可选多渠道来源标注。仅本项目资料 + 用户输入。

## 步骤

1. **预处理**：去重/合并高度相似条目并标注合并数；超短无实质内容单列统计。
2. **逐条登记**：来源渠道、摘要、情感倾向（正/中/负，仅基于原文）、等级（P0/P1…以用户字段为准）、状态、责任人、闭环证据。
3. **分类**：功能缺陷 / 体验 / 性能 / 文档培训 / 商务交付 / 其他——无依据不硬造类目数量。
4. **主题与趋势**：亲和归类 Top 痛点；有时间字段才做环比，否则标「未取得」。多渠道交叉一致处标「三角验证」，冲突并列。
5. P0 未闭环显式列出（G5-3 否决由人判定）。
6. 输出「问题台账 / 主题排序 / 未闭环清单 / 缺项清单」。

## 禁止事项

- 禁止伪造闭环或隐瞒 P0。
- 禁止无样本时编造 NPS 或情感占比。
- 禁止给出 Gate 签署结论。

依据：QoderWork「用户反馈分析」；上游 analyze-feature-requests、retro；六阶段 LC05；五大 Gate G5-3。
