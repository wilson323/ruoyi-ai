# LC08 停产评估与公告

## 目标

产出**停产公告**相关评估材料（深管阻断）。G5 决议为停产时可自动创建本待办（Gate 叙述）。

## 输入

停产理由、库存/在途、客户影响、替代方案、售后窗口、产品组长决策。仅本项目资料 + 用户输入。

## 步骤

1. 整理评估表：理由、影响客户/渠道、库存与服务承诺、替代产品、时间线。
2. 公告草稿仅基于已确认字段；缺决策人确认则标「不可发布」。
3. 输出「评估表 / 公告草稿 / 缺项清单」。

## 禁止事项

- 禁止伪造停产决策或已对客公告。
- 禁止隐瞒未消化库存风险。
- 禁止给出 Gate 签署结论。
