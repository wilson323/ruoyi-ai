# V03 Beta 客户试用与反馈收集

## 目标

产出**Beta 试用报告**（深管阻断），作为 G4-1 产品就绪证据之一。

## 输入

试用客户名单、试用范围/版本、反馈原文或纪要、缺陷单。仅本项目资料 + 用户输入。

## 步骤

1. 核对试用客户与版本；名单空则列缺项。
2. 按客户汇总：场景、满意度信号、问题/缺陷、原话摘录（来源）、行动项（推断须标「推断」）。
3. 主题归类（功能/性能/易用/本地化/集成等）；≤20 条可精读，>20 条以聚合为主并保留代表原话。
4. 多来源（试用纪要 vs 缺陷单）冲突时并列，不单方取舍。
5. 输出「试用覆盖表 / 反馈主题 / 缺陷与行动 / 缺项清单」。

## 禁止事项

- 禁止编造客户反馈或 NPS。
- 禁止把内部自测冒充 Beta 客户试用。
- 禁止给出 Gate 签署结论。

依据：QoderWork「用户反馈分析」（精读/统计分流）；上游 summarize-interview；六阶段 V03；五大 Gate G4-1。
