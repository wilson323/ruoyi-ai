# 可视化 HTML 页面产物（answer-me-with-html）

## 何时使用（判定规则）

同时满足才出页面，否则普通 Markdown 作答：

- 内容有 **≥3 个相互关联的概念/实体**，或一条**多步流程**，或**多向对比**，或**层级结构**；
- 用户要「一页看清」的交付物（汇报材料、方案页、核对单、流程说明）；
- 产物落为 `.html` 文件合理（创建运行时已勾选 `render_html_page` 工具）。

单点问答、两三个要点的短答复：不出页面。

## 工作流（本项目形态，无 shell）

1. **写草稿**：按下文格式写扩展 Markdown 草稿（不写 HTML/CSS/SVG）。
2. **调工具**：调用 `render_html_page`，入参 `draft`（草稿全文）与 `fileName`（以 `.html` 结尾，如 `竞品分析页面.html`）。工具自动完成布局、主题、图表与 STE 检查，产物登记为本次运行草稿。
3. **按回执自修**：
   - 失败回执带 `✗ L<行号> [组件]` 与正确示例——按行号修草稿后重调工具，**最多重试 2 次**；两次仍失败则改用普通 Markdown 表格作答并说明原因。
   - 成功回执带 `STE 警告 N 条`——N>0 时优先按警告修订草稿重渲染一次。
4. **收尾**：正文用 2-3 行说明页面结论与文件名，不复述页面内容。

## 草稿格式速查

````
---
title: 页面标题            # 必填（或正文首行用「# 标题」）
subtitle: 副标题           # 可选
template: sheet            # sheet=多面板看板（默认）| doc=线性长文
theme: auto                # auto|blueprint|shadcn|paper，页面内可切换
cols: 3                    # sheet 网格列数，默认 3
style: 80                  # STE 检查档位：off|80（默认，警告）|strict
---

导语段（可选）。

## 面板标题 {span=2 meta="右上角注"}    ← span 可省略；「## 」开一个面板

普通 Markdown：段落、列表、表格、引用、行内代码。
表格单元格写 ok / no / warn 自动渲染 ✓ / ✗ / ! 徽章。

```flow LR               ← 围栏语言=组件名（九种见下表），后接组件参数
A -> B
```
````

面板标题的字母编号自动分配，不手写。宽表格与图表无需 span，页面按内容自适应。

## 九种组件选型

| 组件 | 用途 | 关键语法 |
| --- | --- | --- |
| `flow` | 流程图/架构图（自动布局） | `A -> B: 标签`；`-->` 虚线；`(圆) [方] {菱} [(库)]`；`*` 高亮；`group 名: A, B` |
| `sequence` | 时序图（参与方消息） | `A -> B: 请求`；`B --> A: 返回`；`note A, B: 注`；`== 阶段 ==` |
| `tree` | 层级树/组织图 | 缩进定层级；`标签 | 灰注`；`*` 高亮；`list` 参数转缩进列表 |
| `timeline` | 时间线/阶段 | `时间 \| 标题 \| 注`；`*` 高亮；`h`/`v` 强制方向 |
| `limits` | 值 vs 上限条 | `标签 \| 值 / 上限 \| 单位 \| 注`；超限自动红 |
| `annot` | 句段标注（下划线+旁注） | `[被注文本]{注}`；`{!红注}`；`# 组题 | 右注` 分组 |
| `kv` | 键值网格/元数据块 | `键: 值`；首 `*` 通栏大字；`cols=2` 列数 |
| `callout` | 结论/提示/警告条 | ` ```callout info\|ok\|warn\err 标题` + 正文 |
| `table`（原生 Markdown） | 对比矩阵/清单 | 单元格 ok/no/warn 出徽章 |

选型原则：流程用 `flow`，交互时序用 `sequence`，从属层级用 `tree`，时间演进用 `timeline`，指标对标用 `limits`，逐句批注用 `annot`，元信息用 `kv`，页面级结论用 `callout`。

## STE 写作规则（默认 80 档警告，strict 档不过不出页）

- 一句一个要点：程序句 ≤20 词、陈述句 ≤25 词；
- 主动语态，避免 "be noted" 类被动；
- 用短词：to 不写 in order to，use 不写 utilize，help 不写 facilitate；
- 名词串 ≤3 个词；只写能验证的事，禁绝对化（always/never 慎用）。

## 禁止事项

- **禁止手写 HTML/CSS/SVG**（包括 ` ```html ` / ` ```svg ` 逃逸围栏）——一切排版交给渲染工具。
- 不做视频/语音（`am video`/TTS/mp4 依赖外网与 Chrome，超出本项目运行边界）。
- 失败两次后不得继续硬试；改普通 Markdown 作答并如实说明。
- 页面内容遵守项目事实纪律：引用项目资料须真实检索，缺资料标「未取得」。
