# LC03 上市后 6 个月终算（回款 + 奖金池）

## 目标

产出**奖金池核算表**输入：上市后 6 个月**回款达成**与池核算所需字段。窗口自 L08 上市日期起算（动作清单 + DOC-01）。

## 输入

| 资料 | 用途 | 获取 |
| --- | --- | --- |
| L08 上市日期 | 6 自然月窗口 | 项目 |
| LC01 回款台账 | 有效回款 R | 项目 / 用户 |
| C08 立项目标 T、C09 差异化系数 | 达成率与池公式输入 | 项目（已锁定） |

DOC-01 公式要点：奖金池与回款口径绑定；T 为立项目标不可用实际回款替代基数。

## 步骤

1. 确认窗口起止与台账覆盖；缺口列缺项。
2. 汇总窗口内净回款 R；引用锁定 T 与差异化系数；计算达成率时缺数不补 0。
3. 整理核算表字段：T、R、达成率、系数、池计算式所用输入（按用户/系统已定公式引用，不另造公式）。
4. 输出「窗口与台账核对 / 核算输入表 / 缺项清单」。

## 禁止事项

- 禁止改写 G1 锁定的 T 或系数。
- 禁止编造回款或达成率。
- 禁止把 G5 复盘结论当作本动作终算已完成。
