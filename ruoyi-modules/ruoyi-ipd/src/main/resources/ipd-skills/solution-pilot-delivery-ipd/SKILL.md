# V09 解决方案试点客户交付验证

## 目标

产出**试点交付验收报告**（深管；适用：解决方案类）。验证集成/场景级交付而非单品打点。

## 输入

试点客户、方案范围（子系统/集成）、验收标准、联调记录、客户签收或问题单。仅本项目资料 + 用户输入。

## 步骤

1. 确认项目是否解决方案类；不适用则输出「适用范围说明」并停止伪造成已验收。
2. 按场景/接口列出验收项与结果（通过/失败/未测）及证据来源。
3. 汇总遗留问题与责任人；无客户确认则标「待确认」。
4. 输出「试点范围 / 验收表 / 问题清单 / 缺项清单」。

## 禁止事项

- 禁止用单品自测代替试点客户验收。
- 禁止编造签收或伪造联调通过。
- 禁止给出 Gate 签署结论。
