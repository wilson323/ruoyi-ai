# P10 认证与法规清单确认

## 目标

按**目标市场**确认认证与法规清单（计划态）。轻管登记；动作清单保留阻断语义，但 **DOC-05** 规定：计划→开发出口对「清单/周期未完」**不得再硬拦**，缺口非阻断跟踪；**不得伪标实际认证已取得**。实际结果由 V02/G4 核验。

## 输入

| 资料 | 用途 | 获取 |
| --- | --- | --- |
| 目标区域/市场 | 带出认证项 | 用户 / 项目 |
| 产品形态（硬/软/方案） | 适用项裁剪 | 项目资料 |
| 周期与上市窗口 | 计划匹配 | 用户 |

内置常用项（动作清单，可手工补其他）：欧盟 CE/RoHS/REACH/GDPR；北美 FCC、UL/ETL、Prop 65；中国 CCC/SRRC/等保/个保法；中东 SABER/SASO、ECAS/EQM；拉美 ANATEL、NOM；亚太 BIS/KC/PSE/MIC/RCM；其他 CB、IEC 62443 等。

## 步骤

1. 列出目标市场 → 映射认证项；允许用户补充「其他」。
2. 每项登记：适用与否、计划周期、责任人、当前状态（规划中/进行中）；**未取得证书不得写已通过**。
3. 周期与上市窗口冲突时记入缺口跟踪（责任人+关闭期限），不宣称可豁免上市结果检查。
4. 输出「市场-认证对照表 / 缺口跟踪 / 缺项清单」。

## 禁止事项

- 禁止把计划清单写成证书已取得。
- 禁止建议以 G2/P10 放行替代 V02/G4 结果门禁。
- 禁止编造证书编号或通过日期。
