## 3. 开关语义

配置键：`ipd.project-agent.enabled`（默认 `false`，`matchIfMissing=false`）。

| 接口 | 关闭时行为 |
|---|---|
| #1 能力 | **HTTP 200 + code=0**；目录仍返回；每个 `pack.available=false`，`unavailableReason` **精确等于** `项目智能体未启用（ipd.project-agent.enabled=false）`（常量含 `ipd.project-agent.enabled=false`） |
| #2 创建 run | 业务错误（`STATE_CONFLICT`），`message` **含** `ipd.project-agent.enabled=false`；**零写入** |
| #3–#5 / #7 | 同上拒绝，零写入 |
| #6 反馈 | 同上拒绝，零写入 |

关闭时不降级到副驾，不装配执行内核 Bean。

## 4. 幂等（创建运行）

- 键：`(tenantId, personId, idempotencyKey)`，键长度 ≤ 64。
- 同人同键**同请求体**（规范化 digest，含可选 `productLineId`）：返回原 `runId` + 当前 `status`，不再次执行。
- 同人同键**不同请求体**：`STATE_CONFLICT`，message 说明幂等键冲突，**不新建运行**。

## 5. 事件分页与 `nextSeq`

```json
{
  "events": [ { "seq": 1, "type": "RUN_STARTED", "payload": {}, "createdAt": "..." } ],
  "nextSeq": 1,
  "terminal": false
}
```

| 字段 | 语义 |
|---|---|
| `afterSeq` | 查询参数；返回 `seq > afterSeq`；缺省 0；负数 → `PARAM_INVALID` |
| `nextSeq` | **已返回事件中的最大 `seq`**；本页无事件时等于请求的 `afterSeq`（游标不变） |
| `terminal` | 当且仅当终态事件（`RUN_FINISHED` 或 `ERROR`）的 `seq ≤ nextSeq`（即已送达客户端） |

客户端轮询：下次 `afterSeq = 上次 nextSeq`。

## 6. 事件 `payload` schema

| type | payload 字段 | 说明 |
|---|---|---|
| `RUN_STARTED` | `{}` 或空对象 | 进入 RUNNING |
| `STEP` | `kind`（string，如 `SKILL_LOADED` / `MODEL_CALL`）；其余明细键（如 `name`/`sha256`） | 不含凭据与推理原文 |
| `TOOL_CALL` | `toolCallId`, `toolName` | 工具开始 |
| `TOOL_RESULT` | `toolCallId`, `toolName`, `state` | 工具结束 |
| `SOURCE` | `toolCallId`, `tool`, `projectId`(string), `query`, `hits`, `chars`, `preview` | 真实检索后才上报 |
| `TEXT_DELTA` | `text` | 合并后的文本块（非逐 token） |
| `ARTIFACT` | `artifactId`(string), `title`, `contentHash`, `version`(number) | SUCCEEDED 且有正文时落 DRAFT 版本后上报；与其它事件同表 |
| `ERROR` | `errorCode`, `message` | 与 `RUN_FINISHED` 互斥；FAILED 收尾 |
| `RUN_FINISHED` | `status`（`SUCCEEDED`/`CANCELLED`） | 与 `ERROR` 互斥 |

终态事件每个 run **恰一个**。

## 7. 反馈（#6）

实现路径：`PUT /api/v1/ai-feedback/{targetType}/{targetId}`（勿另开草案路径）。

| 项 | 约定 |
|---|---|
| `targetType` | **必须是** `RUN_MESSAGE` \| `ARTIFACT_VERSION`（其它 → `PARAM_INVALID`） |
| `RUN_MESSAGE` | `targetId` = `runId`（字符串）；须本人发起且项目可见 |
| `ARTIFACT_VERSION` | `targetId` = `ipd_agent_artifact_version.id`；**仅版本行存在时接受**；不存在 → `STATE_CONFLICT` |
| body | `{ "rating": "UP"|"DOWN", "reason": "≤500 字或省略" }` |
| 幂等 | 同一人对同一目标更新同一行 |
