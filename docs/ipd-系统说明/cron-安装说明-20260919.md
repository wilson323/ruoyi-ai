## 3. 两种安装方式

### 方式 A: 推荐 — 系统级 /etc/cron.d/(一次安装长期生效)

```bash
cd /Users/mac/Documents/ruoyi-ai

# 第一步:dry-run 预览(不真改)
bash scripts/install-cron-reconcile.sh --dry-run

# 第二步:真安装(需 sudo)
sudo bash scripts/install-cron-reconcile.sh --install

# 第三步:验证
bash scripts/install-cron-reconcile.sh --status
```

特性:
- 文件权限 0644(cron.d 标准)
- 装一次长期生效
- 系统重启后自动恢复
- 卸载:sudo bash scripts/install-cron-reconcile.sh --uninstall

### 方式 B: 用户级 crontab(无需 sudo)

```bash
crontab -e
```

加一行:
```
0 2 * * 0 cd /Users/mac/Documents/ruoyi-ai && bash scripts/reconcile-multi-source.sh >> /var/log/ruoyi-ai-cron.log 2>&1
```

特性:
- 无需 sudo
- 用户级独立 crontab
- 卸载:crontab -e 注释该行

## 4. 自证能红(关键)

R119 `reconcile-multi-source.sh` 第 110 行:

```bash
if [ "${DIFFS:-0}" -gt 0 ]; then
  exit 1
fi
```

含义:
- 差异项 = 0 → exit 0(cron 视为成功,不告警)
- 差异项 > 0 → exit 1(cron 视为失败,系统邮件提醒 root)

**意义**:每周日 02:00 自动产出 `docs/ipd-系统说明/事实源对账-YYYYMMDD.md`,若有未对账项(IPD 后端未启、兄弟会话 ry-vue 在跑、ahead 分支超龄)→ 自动告警。

## 6. 一键命令汇总

```bash
# 看现状
bash scripts/install-cron-reconcile.sh --status

# 真安装
sudo bash scripts/install-cron-reconcile.sh --install

# 卸载
sudo bash scripts/install-cron-reconcile.sh --uninstall

# 手动跑一次(等价于 cron 触发的命令)
bash scripts/reconcile-multi-source.sh

# 看 cron 日志
tail -f /var/log/ruoyi-ai-cron.log

# 看最近一份对账报告
ls -lt docs/ipd-系统说明/事实源对账-*.md | head -1
```

## 7. 失败排查

如果周日 02:00 没跑:

1. `bash scripts/install-cron-reconcile.sh --status` 看装没装
2. `cat /var/log/ruoyi-ai-cron.log | tail -50` 看 cron 日志
3. `ls -la /etc/cron.d/ruoyi-ai-reconcile-weekly` 看文件权限
4. macOS 注意:`/etc/cron.d/` 在 SIP 保护下可能不可写,需用方式 B 用户级 crontab
