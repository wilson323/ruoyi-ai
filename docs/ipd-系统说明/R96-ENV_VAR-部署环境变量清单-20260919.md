## 1. 命名规约（定稿）

- 全大写下划线；服务前缀 + 语义后缀：`<SERVICE>_<FIELD>`（如 `SNAIL_JOB_TOKEN`、`MAIL_PASSWORD`、`SMS_ALIBABA_ACCESS_KEY_SECRET`）
- justauth 按 provider 细分：`JUSTAUTH_<PROVIDER>_CLIENT_SECRET`，PROVIDER 取 yml 键名大写（`ALIPAY_WALLET`、`WECHAT_OPEN` 等）
- yml 侧统一写 `${VAR:}`（冒号后默认空）；空值 + 功能开关关闭 = 该功能不启用，不阻塞启动；标记「必填」的变量缺失时启动 fail-fast
- client-id 属 OAuth 公开标识，保留 yml 字面量（多为上游打码示例），不入 env 体系

## 4. 注入位置建议

1. **生产部署**：进程环境变量（systemd `Environment=` / `EnvironmentFile=`、K8s Secret、docker compose `environment:` 均可），禁止写入任何入库文件
2. **本地开发**：本仓约定走 gitignored 的 `.codex/ipd-dev/config/`（本轮已放本地注入说明 `ENV_VARS-inject-guide-20260919.md`，同样不含真值）
3. **docker compose 部署**（`docs/docker/ruoyi-ai/`）：按需在 `backend.environment` 追加上表变量；未配置的功能保持关闭（`enabled: false` / 空值），不影响启动
