```
PRIMARY                 (id)
```

**EXPLAIN 验证**：
```
EXPLAIN SELECT * FROM audit_logs WHERE entity_type = "products" AND entity_id = 12345 LIMIT 1;
type=ref  key=idx_al_entity_type_id  rows=1  filtered=100.00
→ 主路径走索引，性能达标
```

**M-13 处置决策**：❌ **不重建索引**。理由：
1. `2026-09-10-audit-logs-indexes.sql` 早 apply（早于本次 R146 探针 10 天），命名是 `idx_al_*` 而非 09-09 脚本的 `idx_audit_*`，无冲突
2. EXPLAIN 已验证 `(entity_type, entity_id)` 走 `idx_al_entity_type_id` 索引，rows=1
3. 重跑 DDL 是幂等保护（`information_schema.statistics` 存在性检查），但仍会消耗 MySQL 维护窗口，且对 1568 行表无收益
