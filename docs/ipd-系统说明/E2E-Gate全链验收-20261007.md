## 3. F4 —— 终裁落状态：HTTP 路径未能跑到（如实登记，未强行造数）

**卡在哪**：终裁前置要求「两位同组组长意见相左」。本项目所在组 900001 只有 1 位在职组长
（`ipd-leader` 900102；`ipd-leader2` 900112 已 `del_flag=2` 软删且密码不同，登录失败）。

单组长场景下 `maybeEscalateAfterArbitration` 判定「还有组长未提交」为假，且所有已裁意见一致，
走的是**结算**分支而非升级分支。实测审计佐证：
```
GATE_ARBITRATION_OPEN      双PM意见分歧，自动发起组长仲裁
GATE_ARBITRATION          组长仲裁意见
GATE_ARBITRATION_SETTLED  组长仲裁一致：APPROVE     ← 走结算，没升级
```
故 `final-ruling` 返回 `组长仲裁尚未形成两组对立意见，暂无需超管终裁`。

**为什么没有造第二个组长账号**：新建可登录账号是带安全影响的副作用，超出「跑验收」本身，
按纪律须先经 owner 同意，故停在此处并如实登记。

**F4 已有的证据（非 HTTP）**：
- `GateFinalRulingEffectTest` 4 例（`@Tag dev`）：APPROVE 落 APPROVED+审计 / REJECT 自环幂等不 UPDATE /
