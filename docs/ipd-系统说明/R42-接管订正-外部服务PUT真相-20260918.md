## 3. PUT 真相实测(2026-09-18 现查)

### 3.1 现查矩阵

```bash
# 探测时间:2026-09-18 接管轮现查
# 端点:http://127.0.0.1:62250/api/tasks/{uuid}

# 1) 真 UUID PUT 改 status
$ curl -X PUT ".../api/tasks/6028cbed-7e2c-439c-b194-7b30d3ac1e44" \
    -H "Content-Type: application/json" -d '{"status":"inreview"}'
{"success":true,"data":{"id":"6028cbed...","status":"inreview",...}}
---HTTP 200---

# 2) PUT 路径错(v1 前缀)
$ curl -X PUT ".../api/v1/tasks/6028cbed..." -d '...'
---HTTP 405---    # Method Not Allowed(不是 404)

# 3) PUT 假 UUID(R40 误测触发的)
$ curl -X PUT ".../api/tasks/non-existent-uuid-test-9999" -d '...'
Invalid URL: Cannot parse `task_id` with value `non-existent-uuid-test-9999`:
UUID parsing failed: invalid character...
---HTTP 400---    # UUID 解析失败(不是 404)

# 4) OPTIONS
$ curl -X OPTIONS ".../api/tasks/6028cbed..."
---HTTP 405---
```

### 3.2 真相矩阵(订正版)

| HTTP 方法 | 路径 | 真 UUID | 假 UUID | 错路径(/v1/) |
|---|---|---:|---:|---:|
| GET | `/api/tasks/{uuid}` | 200 | 400 | 405 |
| POST | `/api/tasks` | 200 | — | — |
| PUT | `/api/tasks/{uuid}` | **200 ✅** | 400 | 405 |
| PATCH | `/api/tasks/{uuid}` | 200/405 | 400 | 405 |
| DELETE | `/api/tasks/{uuid}` | 200/405 | 400 | 405 |
| OPTIONS | `/api/tasks/{uuid}` | 405 | — | — |

### 3.3 真相结论

- **PUT 路由正常**(真 UUID → HTTP 200)
- **R40 兄弟误测触发的「404 拦截」实际是「400 UUID parsing failed」**,兄弟误读响应码
- **没有 nginx 反代 PUT 拦截**
- 真正"错路径"返回的是 **405(Method Not Allowed)** 而非 404
