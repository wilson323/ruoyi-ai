## 二、抓取方法（grep 路径 + 命令）

### 2.1 后端端点抓取

> 抓 `@RequestMapping` / `@GetMapping` / `@PostMapping` / `@PutMapping` / `@DeleteMapping` / `@PatchMapping`
> 三种形态：(1) 注解带括号引号 `(b) "@XxxMapping("/path")"`  (2) 注解裸用 `@XxxMapping` 无参（端点路径 = 类前缀）  (3) 注解 `value="/path", produces=...` 多属性形式

**关键命令（重做一遍只要 3 秒）：**

```bash
grep -rn -E "^[[:space:]]+@(Get|Post|Put|Delete|Patch)Mapping" \
  ruoyi-modules/ruoyi-ipd/src/main/java/org/ruoyi/ipd/controller/
```

**关键发现**：
- 裸注解（无参）**20+ 处**，全部归到类前缀路径；例 `ProductController @GetMapping` → `GET /api/v1/products`
- `IpdSseController` 用 `@GetMapping(value = "/sse", produces = MediaType.TEXT_EVENT_STREAM_VALUE)` 多行注解，需正则 `value\s*=\s*` 兼容
- `GateSignScanController` **没有类前缀**，方法用绝对路径 `@PostMapping("/api/v1/gates/sign/scan-timeout")`
- `paiban-11` 已把 `BidController` / `RequirementChangeController` / `PmDirectoryController` 的 `@RequestMapping("/api/v1")` 去前缀
  → 这 3 个类的端点路径全部使用完整 `/api/v1/xxx` 子路径，**不会被类前缀误放**

**提取脚本位置**：`/tmp/extract_endpoints_v4.py`（合并跨行 + 兼容裸注解 + 兼容 `value=` 形式）
**输出 dump**：`/tmp/be_endpoints_v4.txt` → **271 method endpoints**（raw 计数，含跨域 Controller 全集）

### 2.2 前端 API 调用抓取

> 抓 `ipdGet(...)` / `ipdPost(...)` / `ipdPut(...)` 调用（第 1 个参数为 path 字符串）。
> 注意 `http.ts` 内部不补 `/api/v1` 前缀（已含）；自动拼接 `/api/v1${path}`。

**关键命令**：

