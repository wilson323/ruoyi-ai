### P0-06 审计链验不出「删尾部」——最常见的销毁证据手法 【已复核】

`AuditLogServiceImpl:240`：`String expectPrev = nvl(all.get(0).getPrevHash())` —— 锚点是**库内当前首行自己**，非外部锚。

- `getLastSeq` 在全仓 main 代码中出现 **0 次** → 验链从不读链头 seq
- `getLastHash` 出现 **1 次**，位于 `:124`（写入路径），非验链路径

删末尾 N 行后：首行前移、邻接哈希自洽、`gaps` 空、`hashBroken` 空 → `verifyChain()` 返回 **OK**。

**缺的就是一行**：验链时读锚行断言 `head.getLastSeq() == all.get(last).getSeq() && head.getLastHash().equals(all.get(last).getCurrHash())`。
且该判据**不能被 `rebuildChain` 修复**，应单列第三类（`TRUNCATED`）。
