## 处置方案:加注释(R103 推荐)

**理由**:
1. 删表风险高——可能有未来业务依赖此表(兄弟 P3 阶段有项目积分/评分链路)
2. 保留(不动)风险也高——表名漂移可能误导新会话以为这是 active 表
3. **加注释**最稳:明确告诉后人"这表是预留,等真活业务落地再启用"

**实施**:在 `docs/wiki/table-annotations.md`(新建)或 `docs/ipd-系统说明/工程合同/数据字典-20260919.md` 加 2 行表注释:

```sql
-- project_scores:预留表(2026-09-19 R103),0 行,等真活业务落地后启用
-- project_score_records:预留表(2026-09-19 R103),0 行,等真活业务落地后启用
```
