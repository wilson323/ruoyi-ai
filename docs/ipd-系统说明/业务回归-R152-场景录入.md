## 1. 业务方操作步骤（按截图定位）

### 1.1 单条录入

| 步 | UI 区域 | 操作 |
|---|---|---|
| 1 | 浏览器 | 登录 `http://127.0.0.1:15800/login`（超管 `ipd-admin / Ipd@123456`） |
| 2 | 左侧菜单 | **「运营管理」** → **「场景管理」** → **「落地场景登记」** |
| 3 | 顶部表单 | 「项目」选 `1001` |
| 4 | 顶部表单 | 「场景代码」填 `SC-R152-001`（业务自定义 ≤ 64 字符） |
| 5 | 顶部表单 | 「场景名称」填 `R152 业务回归-单条` |
| 6 | 顶部表单 | 「落地日期」选 `2026-09-21` |
| 7 | 顶部表单 | 「落地金额」填 `158000.00` |
| 8 | 顶部表单 | 「备注」填 `R152 C 业务回归验证` |
| 9 | 顶部表单 | 点击 **「保存」** |
| 10 | 表格区 | 新增一行；顶部 toast「保存成功」 |

### 1.2 批量导入

| 步 | UI 区域 | 操作 |
|---|---|---|
| 1 | 同上页 | 顶部按钮区点击 **「批量导入」** |
| 2 | 弹窗 | 点击 **「下载模板」** 按钮，浏览器下载 `landed-scenarios-template.json` |
| 3 | 本地 | 按下方 JSON 模板填写 5 条 |
| 4 | 弹窗 | 把填好的 JSON 粘贴进文本框（接受 JSON 数组） |
| 5 | 弹窗 | 点击 **「上传」** |
| 6 | 弹窗 | 弹出 **「成功导入 5 条」** 提示；表格新增 5 行 |

> 批量上限 1000 条/次（`LandedScenarioService.BATCH_IMPORT_MAX`）。

## 2. 期望 HTTP 响应

### 2.1 单条录入（HTTP 200）

```bash
curl -sS -X POST http://127.0.0.1:16040/api/v1/scenarios/landed \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{
    "projectId": 1001,
    "scenarioCode": "SC-R152-C-001",
```

### 2.2 批量导入（HTTP 200）

```bash
curl -sS -X POST http://127.0.0.1:16040/api/v1/scenarios/landed/import \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d @landed-scenarios-template.json
```

**响应体**：
```json
{ "code": 0, "message": "ok", "data": 5, "timestamp": "...", "traceId": "..." }
```

`data` = 成功导入条数。

### 2.3 异常路径

| 异常 | HTTP | code | message |
|---|---|---|---|
| 缺 `scenarioCode` | 400 | 10001 | `scenarioCode 不能为空` |
| `scenarioCode` > 64 字符 | 400 | 10001 | `scenarioCode 长度不能超过 64` |
| 缺 `landedDate` | 400 | 10001 | `landedDate 不能为空` |
| body 不是 JSON 数组 | 400 | 10002 | `JSON parse error` |
| 未带 Token | 401 | 20001 | `未认证或凭证失效` |
