## D1 scopeId 修复

### Bug 现场

业务方跑场景 D 时反馈：选 GROUP scope / scopeId=1001，提交后真库 `scope_id` 列存 NULL。

### 根因

前端表单 `scopeId` 类型为 `string`，但从前端 NumberInput 输入 `1001` 后，form state 直接传 number 1001 给后端；后端 MyBatis 把数字当 BIGINT 写 VARCHAR(64) 列触发隐式转换失败或落 NULL。

### 修复（前端双保险）

`apps/web-antd/src/views/ipd/admin/business-config.vue`：
- L228 form 状态层 `String(scopeId ?? '')` 防御性转换
- L235 body 计算层 `String(scopeId ?? '')` 兜底包装

### 真活验证（D3）

```
API:  POST /api/v1/business-config scope=GROUP scopeId="1001"
DB:   SELECT scope_id FROM ipd_business_config
      WHERE config_key='kpi.approvalRole' AND scope='GROUP'
      → 14 | GROUP | 1001 | kpi.approvalRole | E2E_R152_D3_LEADER ✓
```
