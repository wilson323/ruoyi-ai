### 4.2 本轮阻塞(显式记录)

**R40 P0 blocker — 看板 REST API PUT 改 status 被 nginx 1.28.3 反代 404 拦截**

证据(2026-09-18 现查):
```bash
$ curl -v -X PUT "http://127.0.0.1:62250/api/tasks/{uuid}" -H "Content-Type: application/json" -d '{"status":"done"}'
> PUT /api/tasks/{uuid} HTTP/1.1
> Host: 127.0.0.1:62250
> Content-Type: application/json
> Content-Length: 17
>
< HTTP/1.1 404 Not Found
< Server: nginx/1.28.3
< Content-Length: 0
```

**根因**:`vibe-kanban` 服务用 nginx 1.28.3 反代,nginx 配置层禁了 PUT /api/tasks/{id} 路由。

**影响**:
- `manage.py sync` 用 PUT 改 status → 失败(line 252-255)
- `manage.py set` 改 plan 文件 + 调 reconcile(内部 PUT)→ 失败
- DB-02 plan 文件 ✅ done,但**看板卡片 inprogress 状态无法同步**
- 任何需要通过 plan 文件改 status 的卡,实际看板卡片不动

**修复路径(需 owner 决策)**:
- **A. 修 nginx 配置**(基础设施改动,在 `vibe-kanban` 服务端,不在本仓)
- **B. 降级 manage.py 用 POST + DELETE 替代 PUT**(复杂,会丢 desc 历史)
- **C. 看板卡片双源管理**:plan 文件权威 + 看板卡片只读 + UI 手动翻 status
- **D. 等 owner 拍板** — 本轮 R40 P0 留给 owner
