| `devtoolsminio-data/` | MinIO 早期数据 | < 1MB | 已废数据,几乎无干扰 |
| **`ipd-pm-system/`** | **NestJS + Prisma 早期后端原型** | **42M(占老版 98%)** | **真实代码干扰源** |

**关键事实**:`ipd-pm-system/apps/api/` 是完整 NestJS 工程:
- package.json(name=api, version=0.1.0, 含 nest/prisma scripts)
- nest-cli.json + tsconfig.json + jest.config.js
- src/main.ts + app.module.ts + modules/ + common/ + prisma/
- prisma/schema.prisma + migrations/ + seed.js + sql/
- apps/api/node_modules/(npm 依赖) + apps/api/dist/(构建产物)
- 老版顶层 node_modules/(npm 依赖)

**这是真实可运行 Node.js 工程,不是文档**。任何 AI 工具(IDE / 搜索 / 包管理)可能把它误识为活跃后端,影响包括:
- npm/pnpm 全局搜索污染
- IDE 自动 import 提示推荐老版 NestJS 模块路径
- AI 会话读老版 schema.prisma 当作"数据库 schema 来源"
- 老版 Prisma migration 文件可能被误 apply 到 MySQL(虽然 MySQL vs SQLite 类型差异会挡掉,但仍可能误触发诊断)

R39 我没看子目录就报告"老版只是决策草稿",**误判了真实干扰源**。R40 矫正。
