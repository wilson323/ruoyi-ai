## §一 背景与问题定位

R185-P1 前端 `hasAccess()` 闸已实装（commit `1daeab6`，vitest 992/992 PASS），但 `accessStore.accessCodes` 仍为空 → 所有非超管用户路由级闸被全拦截 → 业务误伤。

**根因链**：
1. 后端 `/auth/me` 不发 `accessCodes`（MeView 仅有 `person/scope/mustChangePwd`）
2. 前端 `vben-identity.ts:34-37 vbenCodesOf()` 非超管只返回 `[scope, 'personType:xxx']`
3. 结果：accessCodes 永远是空数组 → `hasAccess()` 永远 false → 路由全拦截

**现有事实源**（实测）：
- `IpdAuthController.java:79-84` `/auth/me` 返回 `MeView(person, scope, mustChangePwd)`，**无 accessCodes 字段**
- `IpdAuthController.java:38-44` `PersonView` 仅有 `id/name/username/personType/groupId/accountStatus`，**无权限码字段**
- 前端 `vben-identity.ts:34-37` `vbenCodesOf()` 非超管只派生 `[scope, 'personType:xxx']`
- `IpdPermissionCode.java`（已存在）：~60 个 `OPERATION_*` 常量（值如 `ipd:project:list`）
- `IpdRolePermissionCatalog.java`（已存在）：personType → 权限码集合映射

public record PersonView(String id, String name, String username, String personType,
                         String groupId, String accountStatus,
                         List<String> permissionCodes) {
    public static PersonView from(Person p, List<String> codes) {
        return new PersonView(String.valueOf(p.getId()), p.getName(), p.getUsername(),
            p.getPersonType(), p.getGroupId() == null ? null : String.valueOf(p.getGroupId()),
            p.getAccountStatus(), codes);
    }
}

// 2. /me 接口调用新增权限码映射
@GetMapping("/me")
public ApiV1Response<MeView> me() {
    Person person = session.currentPerson();
    List<String> codes = permissionCodeMapper.codesOf(person);
    return ApiV1Response.ok(new MeView(PersonView.from(person, codes), authService.scopeOf(person).name(),
        "1".equals(person.getMustChangePwd())));
}

### B. 新增权限码映射服务

**新增文件**：`IpdPermissionCodeMapper.java`
**改动量**：~50 行（含 4 个 personType 分支映射）

```java
package org.ruoyi.ipd.security;

import org.ruoyi.ipd.domain.Person;
import org.springframework.stereotype.Component;

import java.util.List;

import static org.ruoyi.ipd.security.IpdPermissionCode.*;

/**
 * R185-P1 权限码映射服务：将 Person(personType + groupId) 映射为真实 IPD 业务权限码。
 * 单一事实源：所有路由 meta.access 引用 IpdPermissionCode.* 常量，
 * 本服务保证 v-access:code + hasAccess() 双闸能拿到真实码。
 *
 * 引用：IpdRolePermissionCatalog（已有 personType 角色定义）+ IpdPermissionCode（已有权限码常量）
 */
@Component
public class IpdPermissionCodeMapper {
    public List<String> codesOf(Person person) {
        return switch (person.getPersonType()) {
            case "SUPER_ADMIN" -> List.of("*:*:*");
            case "MARKET_PM" -> List.of(
                OPERATION_PRODUCT_GROUP,
                OPERATION_PRODUCT_GROUP_CREATE,
                "ipd:bid-invitation:admin-assign"
            );
            case "RD_PM" -> List.of(
                OPERATION_MODULE_PROJECT,
                OPERATION_MODULE_PROJECT_QUERY,
                OPERATION_GATE_REVIEW
            );
            case "GROUP_LEADER" -> List.of(
                OPERATION_MODULE_PROJECT,
                OPERATION_STAGE_ACTION
            );
            default -> List.of();
        };
    }
}
```

### C. 前端 vben-identity.ts 改造

**改动文件**：`apps/web-antd/src/store/vben-identity.ts`
**改动量**：~15 行

```typescript
// 改动前：/auth/me 不发 codes，vbenCodesOf 派生空集
export function vbenCodesOf(personType: string, scope: string): string[] {
  if (personType === 'SUPER_ADMIN') return ['*:*:*'];
  return [scope, `personType:${personType}`].filter(Boolean);
}

// 改动后：/auth/me 发 codes，identity 携带直接使用，vbenCodesOf 退化为 fallback
export interface IpdIdentity {
  // ... 既有字段
  accessCodes?: string[];  // 新增：后端 /auth/me 发的真实权限码
}

// ipd-auth store 在 refreshIdentity 时把 codes 灌入 accessStore
async function refreshIdentity() {
  const me = await fetchMe();
  identity.value = { ...me.person, accessCodes: me.person.permissionCodes };
  accessStore.setAccessCodes(me.person.permissionCodes ?? []);
}

// vbenCodesOf 仅在 offline / 缓存身份场景作 fallback
export function vbenCodesOf(personType: string, scope: string, fallbackCodes?: string[]): string[] {
  if (fallbackCodes && fallbackCodes.length > 0) return fallbackCodes;
  if (personType === 'SUPER_ADMIN') return ['*:*:*'];
  return [scope, `personType:${personType}`].filter(Boolean);
}
```
