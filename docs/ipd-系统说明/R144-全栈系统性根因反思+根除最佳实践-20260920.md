## §1 反思源点（不是推算，是真实跑通过程中实测命中）

**真实跑通过程中**（按时间顺序）实测命中的根因：

## §2 根因分层分类（10 根因 × 4 层）

### 2.1 环境层（Environment Layer）— 4 条根因

| 根因 | 类型 | 根因分层 | 根治手段 |
|---|---|---|---|
| A. 环境变量默认值撞库 | 物理层 | 默认值假设 vs 实际值 | **L1**：application-ipd-local.yml 显式覆盖（gitignored，已做）<br>**L2**：CI 启动前必跑 `mysql ping -h $DB_HOST -P $DB_PORT` 检测<br>**L3**：DB 连接工厂启动前 dry-run（连接池预热 + database_exists SQL） |
| B. 端口被僵尸占 | 进程层 | 兄弟会话未清理残留 | **L1**：`lsof -t -i:16039` + `kill -9`（已做）<br>**L2**：启动脚本前强制清场 `preflight-port-clean.sh $PORT`<br>**L3**：worktree 隔离原则下，每个会话自管 PID，结束 30s 内主动 SIGTERM |
| C. Redis 密码默认值 | 配置层 | null 字符串假设 vs 实际行为 | **L1**：redis.conf 显式 `requirepass ""` 或不设（已做）<br>**L2**：连接池初始化后 `PING` 健康检查，失败立即 fail-fast<br>**L3**：RedissonConfig 显式 `setPassword(null)` 不发 AUTH |
| F. Spring profile 不生效 | 配置层 | jar 内 application.yml 优先级最高 | **L1**：`--spring.config.additional-location=optional:file:...`（已做）<br>**L2**：禁用 jar 内 application.yml 用 `<excludes>` 排除<br>**L3**：全部配置外置到 `.codex/ipd-dev/config/` gitignored 目录 |

### 2.2 进程层（Process Layer）— 2 条根因

| 根因 | 类型 | 根因分层 | 根治手段 |
|---|---|---|---|
| G. mvn 子进程被回收 | 进程层 | mvn 父进程退出带子进程走 | **L1**：改 `java -jar` 直接起（已做）<br>**L2**：`exec java -jar` 替换 shell（PID 1 即 java）<br>**L3**：用 systemd / launchd / pm2 持久化（macOS 上 brew services） |
| B. 僵尸进程 | 进程层 | 兄弟会话未清理残留 | **L2**：`preflight-port-clean.sh` 强制清场（同上） |

### 2.3 代码层（Code Layer）— 2 条根因

| 根因 | 类型 | 根因分层 | 根治手段 |
|---|---|---|---|
| D. vite 7.x resolve 别名移除 | 代码层 | Node ESM 规范收紧 | **L1**：显式 `import { resolve as resolvePath } from 'path'`（已做 commit 0c7ad36）<br>**L2**：vite 升 7.x 时 CI 必跑 `vite dev` + curl 首页 200<br>**L3**：vite.config.mts 全部走 `path.resolve` 显式路径别名，禁用全局 polyfill |
| I. Sa-Token 认证头 | 契约层 | 框架默认 Bearer vs 历史 X-Access-Token | **L1**：后端 `sa-token.interceptor` 显式声明 `readHeader: "Authorization"`<br>**L2**：前端 `http.ts` 统一封装 Bearer，绝不传 X-Access-Token<br>**L3**：契约门禁扫 `@SaCheckLogin` Controller 端点 + 前端请求头一致性 |

### 2.4 工具链层（Tooling Layer）— 2 条根因

| 根因 | 类型 | 根因分层 | 根治手段 |
|---|---|---|---|
| E. Python 反代不会 upgrade | 工具链层 | 自写工具未实现 WebSocket upgrade | **L1**：补 `_proxy_ws` + 双向 relay 线程（已做）<br>**L2**：用现成反代（nginx `proxy_http_version 1.1; proxy_set_header Upgrade $http_upgrade;`）<br>**L3**：vite dev 启用 `ws: true`（原生支持，比 Python 反代靠谱） |
| H. shell PATH 丢失 | 工具链层 | macOS launchd PATH 不继承 + zsh 非交互 | **L1**：Bash 工具内 `export PATH="/usr/bin:/bin:..."` 全路径化（已做）<br>**L2**：用全路径 `/usr/bin/curl /bin/sleep /usr/sbin/lsof` 不依赖 PATH<br>**L3**：写一个 `preflight-env.sh` 加 `#!/bin/bash -lc` 强交互 |

### 2.5 认知层（Cognition Layer）— 1 条根因

| 根因 | 类型 | 根因分层 | 根治手段 |
|---|---|---|---|
| J. 表名前缀假设错误 | 认知层 | 推算 vs 实查 | **L1**：`SHOW TABLES` 现查（已做）<br>**L2**：lombok `@TableName("projects")` 注解 + 真库 schema 一致性门禁<br>**L3**：OpenAPI 生成的 TypeScript DTO 含完整字段约束 |


**关键洞察**：
- 工具链层（D + H + E）= 54.5%，是最大拖累
- 环境层（A + C + F）= 27.3%
- 代码层（D + I）+ 进程层（B + G）+ 认知层（J）= 18.2%

**根除 ROI 排序**（高优先级先做）：
1. **H. PATH 丢失** → 一行 `export PATH=...` 即可消除 22.7% 耗时
2. **D. vite 死锁** → CI 加 vite dev 健康检查（commit `0c7ad36` 已修，但下游项目也需同步修）
3. **E. WS 400** → 直接用 nginx / vite dev `ws:true`，放弃 Python 反代兜底
4. **C. Redis 密码** → RedissonConfig 显式 null 不发 AUTH

## §4 根除最佳实践（六道防线 R144 升级版）

R142 五道防线 + R144 新增第六道防线 → **R144 六道防线**：

### 防线 1：环境层契约单一事实源（治 A/C/F）
- 所有 ipd_dev / 13306 / redis / 6379 / 16039 / 15666 等环境参数写进 `.codex/ipd-dev/config/` 下的 5 个 gitignored 配置文件
- 启动命令前缀 `bash -lc 'source .codex/ipd-dev/env.sh && exec java -jar ...'`
- 验证指纹：`mysql --defaults-file=.codex/ipd-dev/config/mysql-client.cnf -e 'SELECT 1'` + `redis-cli -p 6379 ping` + `curl :16039/actuator/health`

### 防线 2：进程层强校验 + 持久化（治 B/G）
- 每个会话启动前必跑 `preflight-port-clean.sh $PORT`（杀同端口进程）
- 禁止 `mvn spring-boot:run`，统一 `java -jar` 直起 + `nohup ... &` + `disown`
- macOS 上 `brew services` 或 launchd 持久化（脱离 shell lifecycle）

### 防线 3：代码层升级即回归（治 D/I）
- vite / webpack / Node 升级前必跑 dev server 启动 + HTTP 200
- Sa-Token 认证头统一封装在 `@/utils/http.ts`，绝不允许散落
- 契约门禁 `check-sa-token-header-consistency.sh` 扫前端请求头 + 后端 interceptor 一致性

### 防线 4：工具链层全路径化（治 E/H）
- 所有 Bash 命令前缀 `/usr/bin/` `/bin/` `/usr/sbin/` 全路径，禁依赖 `$PATH`
- WebSocket 反代首选 nginx / vite `ws:true`，自写 Python 反代仅作 P0 应急
- `preflight-env.sh` 模板固化 PATH 注入

### 防线 5：认知层现查不推算（治 J）
- 表名 / 端口 / hash / 段号 / 凭据 五必现查（已写入 R13 五必现查规约，本轮复用）
- Lombok `@TableName` + 真库 schema 一致性门禁
- OpenAPI → TypeScript DTO 自动生成（消除手抄）

### 防线 6（**R144 新增**）：跨会话撞车 0 让路工具化（治 G 兄弟会话残留）
- `.gitignore` 加 `.vite/`（vite 构建产物，禁止入库）
- `preflight-worktree-check.sh`：commit 前扫工作树 untracked，分类「本会话 / 兄弟会话」并自动 stage 仅本会话
- 兄弟会话 `reports/worktree-*.md` 一律保留不动（撞车 0 让路红线）
