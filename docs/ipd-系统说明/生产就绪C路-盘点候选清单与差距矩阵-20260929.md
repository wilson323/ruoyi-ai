## 3. C1 切片变更（本轮唯一源码改动）

**问题**：`buildAgent` 工作区原为 `workspaceRoot/<agentId>` 平铺——跨项目、跨用户的同一数字员工**共写同一目录**（W3 开放文件工具后即串桶数据泄漏）；`KernelScopeKey` 四维收口只覆盖 stateStore 键，文件面漏 project/user 维。

**变更**（[AgentScopeChatKernel.java](../../ruoyi-modules/ruoyi-chat/src/main/java/org/ruoyi/chat/kernel/AgentScopeChatKernel.java)，+38/−10）：
- `AgentConfiguration` 缓存键补 `projectId/userId`（换桶即换 Agent 实例，防跨桶复用绑定旧工作区的 Agent）；
- `workspaceFor(root, projectId, userId, agentId)` → `root/<project>/<user>/<agent>` 三级分桶，与 `KernelScopeKey` 同源语义；
- `workspaceSegment()` fail-closed：段为空、`.`、含 `:`、`/`、`\`、`..` 一律 `IllegalArgumentException`（防工作区路径穿越）；
- W1 兼容面 `agent(String,String)` 降级到 `__unscoped__/__unscoped__/<agent>`，**旧平铺桶不再产生**；
- 反射锁签名 `agent(String,String)`（`AgentScopeKernelBoundaryTest:37,80`）与 W1 空工具断言原样保留。

**正反例**（新测试 [AgentScopeChatKernelWorkspaceIsolationTest.java](../../ruoyi-modules/ruoyi-chat/src/test/java/org/ruoyi/chat/kernel/AgentScopeChatKernelWorkspaceIsolationTest.java)，`@Tag("dev")`，4 用例全绿）：

3. `workspaceSegmentInjectionIsRejected`：16 组注入（`:`/`..`/`/`/`\`/`.`/空/null × 三维）全部拒绝且**零落盘**；
