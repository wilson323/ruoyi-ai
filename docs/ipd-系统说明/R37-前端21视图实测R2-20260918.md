## 4. R33 教训反转点(关键章节)

### 4.1 KPI 月数 disabled 真相
**R33 误判曾认为**:"KPI 月份控件永久禁用 = 业务禁用"。  
**R2 实测真相**(`/ipd/kpi/index.vue`):

```vue
<!-- line 125 -->
<input v-model="period" type="month" class="filter-input" :disabled="loading" />
<!-- line 129 -->
<select v-model.number="periods" class="filter-input" :disabled="loading">
<!-- line 136 -->
<button class="primary-btn" :disabled="loading" @click="load()">查询</button>
```

- `:disabled="loading"` 是 **loading-driven**(数据请求中禁用)
- `loading` 仅在 `load()` 函数 try/catch/finally 中切换(行 88-110),请求结束立即恢复
- **结论**:R33 误判,R2 实测确认这是 loading 驱动,**非永久禁用**

### 4.2 全局 disabled 模式审计
| 模式 | 处数(估) | 触发条件 | 是否合规 |
|---|---|---|---|
| `loading` 驱动 | ~30 | `if (loading.value) return; loading=true; ... finally loading=false` | ✅ 标准模式 |
| 业务守卫 `!required \|\| loading` | ~20 | 表单字段未填齐 或 加载中 | ✅ 标准模式 |
| 权限守卫 `v-access:code="..."` | ~5 | 权限码缺失 | ✅ R33 后规范化 |
| **永久禁用 + title** | 1(review/index.vue:252 双周评审) | 后端端点未交付 | ✅ **G-06 规范(不假绿)** |
| 永久禁用 无 title | 0 | — | ✅ 无残留 |

### 4.3 canQuery / view 权限实测
- 路由级:`meta.access` + `meta.authority`(personType 角色)
- 组件级:`v-access:code` 指令(自定义 R33 修复)
- 业务守卫:每个 mutating button 都加 `:disabled` 双保险
- **结论**:本轮静态分析无 R33 式"loading 误判为业务禁用"的回归
