**对应接口**：`POST /api/v1/recovery/check-90d` · `GET /api/v1/recovery/warnings`
**对应真库表**：`recovery_warnings`（R149 batch2a 新建）+ 阈值种子 `ipd_business_config` 中 `recovery.threshold`（默认 0.25）

### 2.3 异常路径

| 异常 | HTTP | code | message |
|---|---|---|---|
| `scanDate` 格式错（不是 ISO DATE） | 400 | 10003 | `Failed to convert value ... to LocalDate` |
| 未带 Token | 401 | 20001 | `未认证或凭证失效` |
| 角色非组长/超管（如 MARKET_PM） | 403 | 20003 | `无操作权限`（service 二次校验 `requireLeaderOrAdmin()`） |

## 3. 真库验证 SQL

```sql
-- 行数核验（步骤 1.2 完成后应见 3 行）
SELECT COUNT(*) AS warning_cnt FROM recovery_warnings WHERE del_flag = 0;
-- 实测：3 ✓

-- 详情核验
SELECT id, project_id, warning_date, days_since_launch, recovery_rate, threshold, status
  FROM recovery_warnings
 WHERE del_flag = 0
 ORDER BY warning_date DESC LIMIT 10;
-- 期望：
-- project_id IN (9140001, 9140002, 9140003)
-- warning_date=2026-06-22 | days_since_launch=90
-- recovery_rate=0.0000 | threshold=0.2500 | status=PENDING

-- 阈值种子核验（默认 0.25）
SELECT config_value FROM ipd_business_config
 WHERE scope='GLOBAL' AND config_key='recovery.threshold';
```
