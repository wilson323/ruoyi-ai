## 二、26h 切流飞手计划（5 阶段）

### 阶段 1：HrTokenClient 切 Redis（4h）

- 文件：`ruoyi-modules/ruoyi-ipd/src/main/java/org/ruoyi/ipd/hr/HrTokenClient.java`
- 改造点：
  - `ConcurrentHashMap<String, String>` 内存缓存 → `RedisTemplate.opsForValue().set(key, value, ttl)`
  - key 约定：`ipd:hr:token:{tokenId}`（全局 key 前缀 `ipd:`）
  - TTL：默认 30min（HR token 寿命）
- 测试：`HrTokenClientTest.java` 新增 3 个用例（set/get/expire）
- 工作量：4h
- 撞车：低（接口已隔离，IPD 模块独立）

### 阶段 2：BusinessConfigServiceImpl pub/sub（8h）

- 文件：`ruoyi-modules/ruoyi-ipd/src/main/java/org/ruoyi/ipd/service/impl/BusinessConfigServiceImpl.java`（如不存在则新建）
- 改造点：
  - 单实例本地缓存 → 多实例共享缓存
  - 配置 invalidate 时发 pub/sub `ipd:business-config:invalidate:{configKey}`
  - 订阅方收 invalidate 后清本地缓存
- 边界处理：`SCOPE_CACHE` 模糊匹配（按 R194 §A7 §七 7.1 提示）
- 工作量：5h 改造 + 3h 测试
- 撞车：**中**（SCOPE_CACHE 模糊匹配边界 + 多实例同步语义）

### 阶段 3：application.yml 新增 Redis 配置（2h）

- 文件：4 个 yml（dev/staging/prod/local）
- 新增段：
  ```yaml
  spring:
    data:
      redis:
        host: ${REDIS_HOST:127.0.0.1}
        port: ${REDIS_PORT:16379}
        database: ${REDIS_DB:0}
        password: ${REDIS_PASSWORD:}
        timeout: 2000ms
  redisson:
    config: |
      singleServerConfig:
        address: "redis://${spring.data.redis.host}:${spring.data.redis.port}"
        database: ${spring.data.redis.database}
        password: ${spring.data.redis.password}
  ```
- 工作量：2h
- 撞车：低（仅新增段不动既有）

### 阶段 4：Testcontainers + 多实例 IT（8h）
