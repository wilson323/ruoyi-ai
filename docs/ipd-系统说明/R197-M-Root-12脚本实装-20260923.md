### 3.1 check-multigates-sync.sh 关键设计

- **风格基线**：参照 `check-bcp-unit-mismatch.sh`（R185 同主题）+ `check-three-source-hash.sh`（R142 三源对账）
- **`set -euo pipefail` + `SCRIPT_DIR/REPO_ROOT` 自发现 + `*_OVERRIDE` 环境变量覆盖**（门禁自测）
- **`MULTIGATES_FAIL_SEED=1` 双向触发**：默认 → exit 0/1；FAIL_SEED → exit 2；DRY_RUN → 旁路 exit 0
- **`MG_TARGETS=1,2,3` 子集限定**：用 for+case 改写（设计稿 case 只匹配首分支的 bug 已修）
- **`SKIP` 语义**：前端仓独立（`apps/web-antd` 不在本仓）→ 记 SKIP 不计 FAIL（撞车 0 软化）
