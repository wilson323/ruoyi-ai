### 2.3 Surefire 过滤策略(从父 pom 提取,这是假绿陷阱根因)


profiles 默认激活:`local`(`<profiles.active>local</profiles.active>`)。

### 4.1 R25 病根 ①:测试没跟上

| 证据 | 结论 |
|---|---|
| ruoyi-ipd 共有 238 个 `*Test.java`,test-compile PASS(产物已生成) | 测试类**存在且可编译**,不是"测试缺失" |

**反证结论**:R25 病根 ① 不是"测试没跟上",而是"**测试打错标签 + Surefire 过滤策略默认跑错组**"——**架构性假绿**。即使后续补再多的测试类,只要不打 `local` 或不切换 profile,都不会跑。

## 6. 总结(给后续 Agent 的指针)

### 6.1 高优风险(必须治理)

1. **Surefire groups 假绿**(R25 病根 ① 真身):`mvn test` 默认跑 0 个测试,但 BUILD SUCCESS。任一 CI 流水线若直接跑 `mvn test` 都会假绿。**唯一修法**:
   - 选项 1:加 `-P dev`(激活 dev profile)→ groups=dev → 238 全跑
   - 选项 2:测试类打 `@Tag("local")` 至少覆盖冒烟子集
   - 选项 3:`mvn test -Dgroups=dev`
2. **archived_at 覆盖率 3.85%**(P2-7.4 教训复现):12 张核心业务表只有 `projects` 有归档字段。后续任何"软删除"功能上线都会再撞同一坑。
3. **5 处文档失真**:每条都有具体行号、对应到 5 个事实源过期点,需要按 naming-convention.md §二口径逐条改。

### 6.2 中优风险

4. **测试目录无 `resources/`**:testCompile 输出 `skip non existing resourceDirectory`,意味着 application-test.yml 类不存在,集成测试要么 mock 要么硬编码。
5. **MySQL 连接走 socket 而非 TCP**:当前 `.cnf` 强制 socket,但 JDBC 端点是 TCP 13306。两者并存(本机原生 mysqld 既开 socket 又开 TCP),任何远端 Agent 都得切换模式。

### 6.3 低优观察

6. **9 张 NOT_EXISTS 表**(任务清单与 DB 实际差异):可能是 v3 文档规划后未落 schema,也可能是名称记忆偏差。需对照 v3 PDF 原始需求表,本报告不去伪造已发生的需求。
7. **23 张抽样表 `update_time IS NULL`**:INFO_SCHEMA 估值偏差,真实业务可能有写。本 Agent 不下业务结论。
