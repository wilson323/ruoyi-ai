### M3. API 调用函数约定(关键 SSOT)

**底座原约定**:`http.{get,post,put,delete,patch}()` / `requestClient.xxx()`(来自 `@vben/common-ui`)。  
**IPD 实际约定**:**`ipdGet / ipdPost / ipdPut`**(来自 `apps/web-antd/src/api/ipd/http.ts`),辅以 `requestIpd`(auth-only 包络层,见 `api/ipd/auth.ts`)。

| 约定函数 | 来源 | 角色 | 出现频次 |
|---|---|---|---|
| `ipdGet` `ipdPost` `ipdPut` | `./http.ts` | 业务 CRUD | 50+ 处 |
| `requestIpd` | `./auth.ts` | 仅 login/me/logout/refresh/auth 包络 | 4 处(`/auth/login` `/auth/me` `/auth/refresh` `/auth/logout`) |
| `http.xxx` `requestClient.xxx` | `@vben/common-ui` | 框架原 | 0 处(在 IPD 业务侧被替换) |

**为什么这样设计**:`http.ts` 注释明确写"自动携带会话 token 并复用 ipd-auth 的轮换/重试逻辑",这是 IPD 业务侧为 Sa-Token + 字符串 ID + code=0 包络的**业务级 override**,**不视为违规**。**约定 SSOT 落档**:`apps/web-antd/src/api/ipd/http.ts` 是 IPD 业务侧唯一调用入口,**禁止直接用 fetch / axios / requestClient**。
