## 二、RAG 真活触发的三种方法(按风险/污染度排序)

### 方法 A:后端审核 API 触发(推荐,污染度低,可审计)

**前置**:已有一个 `ai_documents.status='GENERATED'` 的文档真活(真库当前 4 行:doc_id=2097190178236985345 / 2097190178681581569 / 2097867527915900930 / 2097871649050267649,其中后两条状态是 **GENERATED/REVIEWED**)。

**步骤**:

1. 启后端:`cd ruoyi-admin && mvn -o package -DskipTests && java -Xmx2g -Duser.timezone=Asia/Shanghai -jar target/ruoyi-admin.jar --spring.profiles.active=ipd-local,dev --spring.config.additional-location=file:../.codex/ipd-dev/config/ --server.port=16039`
2. 登录拿 JWT:`curl -s -X POST http://127.0.0.1:16039/api/v1/auth/login -H "Content-Type: application/json" -d '{"username":"ipd-admin","password":"Ipd@123456"}' | jq .data.token`
3. 触发 review(`AiDocumentService.review`):
   ```bash
   curl -s -X POST http://127.0.0.1:16039/api/v1/ai-documents/2097871649050267649/review \
     -H "Authorization: Bearer <TOKEN>" \
     -H "Content-Type: application/json" \
     -d '{"decision":"approve","comment":"L0-1 trigger"}'
   ```
4. 异步等 5-10 秒,验真活:`SELECT COUNT(*) FROM ai_doc_embeddings WHERE doc_id=2097871649050267649;`

**预期**:embedAsync 进入守护线程 → 调 `aiGateway.embed(test-embed at 127.0.0.1:8765)` → `embeddingMapper.insert` 写入。若 endpoint `http://127.0.0.1:8765` 真活 mock,行数 ≈ 2-3(取决于文本切片数,固定 800 字符窗)。

**风险**:低(走标准审核流,审计 trail 完整,无业务表副作用)。

**回滚**:N/A(审核流本身是单向状态递进,误审可走 REJECTED 流不向量化)。

### 方法 C:直接 SQL INSERT 假活(高污染,**禁止走**,仅作应急文档)

```sql
-- 严禁!仅作应急参考 —— 真实数据必须经 embedAsync 路径产出,否则 chunk_text / vector_json 与
-- 实际 ai_documents 内容脱节,L0-3 retrieveContext 余弦检索会返回语义错误片段
INSERT INTO ai_doc_embeddings
  (doc_id, project_id, doc_type, title, chunk_seq, chunk_text, embed_model, vector_json, tenant_id, del_flag)
VALUES (...);  -- ⛔ 不要在没有真活向量的情况下写 vector_json
```

**为什么禁止**:
- `vector_json` 是 OpenAI 兼容 `/embeddings` 接口的 float[] JSON 序列化,长度固定(取决于模型维度);手写无法保证语义对齐
- `chunk_text` 与 `chunk_seq` 必须与 `AiDocEmbeddingService.splitChunks(content, CHUNK_SIZE=800)` 一致(固定窗口无重叠)
- 即使手写能跑通,后续 `retrieveContext` 余弦相似度会因向量维度/分布不匹配而检索质量退化

**唯一例外**:owner 拍板的 "test-only" 探针场景,且必须打 `__manual_seed_for_test` 注释。
