## §2 验收前置修复（验收阻断项根除）

### 2.1 R149-v1 装配链 bug → 应用启动失败（fix commit `2aecfff7`）

- **现象**：`java -jar ruoyi-admin.jar` 报 `APPLICATION FAILED TO START: Parameter 3 of constructor in HrSyncController required a bean of type 'HrSyncJob'`
- **根因链（两个 domino）**：
  1. `HrSyncJob` 有 `@ConditionalOnExpression`（ipd.hr.enabled 默认 false 时不装配），但 `HrSyncController` 无条件创建 + `private final HrSyncJob` 强注入 → 注入失败炸应用
  2. `HrSignatureUtil` 漏 `@Component`（R149-v1 新增类），被 `HrApiClient`/`HrTokenClient` 强注入 → 第二 domino
- **修复**：
  - `HrSyncController`：`ObjectProvider<HrSyncJob>` + `ObjectProvider<RealHrSyncAdapter>` 延迟解析；未装配时 sync 端点抛 `HR_SYNC_NOT_ENABLED`、last-run 返回 null（从未运行）
  - `HrSignatureUtil`：补 `@Component`
  - `ApiV1ErrorCode`：新增 `HR_SYNC_NOT_ENABLED(50018)` + getHttpStatus 409 分支
- **验证**：应用启动 `Started RuoYiAIApplication in 11.758 seconds` PASS + 8 新端点全部 401（注册成功）

### 2.2 前后端产物旧版
