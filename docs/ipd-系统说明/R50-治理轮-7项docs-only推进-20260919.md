### A7:check-param-drift.sh 加 NUMERIC_TOLERANCE 需求 + 设计

**需求**:
- 漂移检测对纯数值差异容忍(`0.05` vs `0.0500` 视为相等)
- 阈值: `NUMERIC_TOLERANCE=0.0001`(默认)
- 可配置:`--tolerance <float>` 参数

**设计**(伪代码):
```bash
function is_drift() {
    local current="$1"
    local default="$2"
    if [[ "$current" == "$default" ]]; then
        echo "false"
    elif is_numeric "$current" && is_numeric "$default"; then
        local diff=$(echo "$current - $default" | bc -l | abs)
        if (( $(echo "$diff < $TOLERANCE" | bc -l) )); then
            echo "false"
        else
            echo "true"
        fi
    else
        echo "true"
    fi
}
```

**撞车 0**:不擅自改 worktree 内脚本(留 owner 拍板)。
