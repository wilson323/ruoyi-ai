### D15 的方法论价值（「单测绿 ≠ HTTP 闭环」又一例）

`@Size` 只适用于 String / 集合 / 数组，用在 Integer 上会在**请求进入时**抛 HV000030。而单测直接调用 service 方法**不经过 `@Valid`**，所以此前全模块测试全绿、线上恒 500。堵法：P231 用例改用真 `Validator` 校验注解本身（7 个无违规 / 0 与 91 越界各 1 违规），让「注解用错类型」这类缺陷在测试层就会红。
