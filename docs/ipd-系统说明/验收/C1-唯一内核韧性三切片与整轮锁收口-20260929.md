## 2. 根因修复：整轮锁实例级 → JVM 级共享

- **现象**：DUAL 双实例并发用例 100% 复现 `KERNEL_STREAM_ERROR`，内层 cause = `State` 抽象类型反序列化失败；真库实证失败槽位 JSON 无 `@class` 类型信息（但历史成功槽位同样 `has_typeinfo=0` → 非 codec 缺陷，是并发撕裂）。
- **根因**：`turnGate` 为实例字段，同 JVM 双实例（多注入点/双副本）同 slot 无整轮互斥 → 并发保存 CAS 版本化状态相互覆盖撕裂。
- **修复**：`AgentScopeChatKernel` L96 `private static final SessionTurnGate TURN_GATE = new LocalSessionTurnGate()`（JVM 级静态共享，SDK `LocalSessionTurnGate` 本身即 `Map<slotId, Semaphore>` 可共享、无资源释放问题）。类注释如实收窄为「JVM 级共享，跨 JVM 多副本串行须另行验收」——**跨进程分布式锁仍是 C1 遗留项**。
- 附带：异常日志补 message（原只记 errorType，诊断盲区），仅日志面、不外泄客户端。
