## 2. 方法与防假绿设计

1. **限流规避**：`IpdAuthController` 登录限流 5/60s，探测全程仅登录 2 次（初探 + 404 复核），其余全部复用 Bearer token。
2. **零写副作用**：所有 POST/PUT/DELETE 不发真实写请求——用 GET 打同路径：405 = 方法未注册但路径已注册；200/400 = 同路径 GET 存在 = RESTful 资源路径确认注册。
3. **404 二次鉴别**：首轮 20 个 404 全部复读 body——**20/20 均为业务 404**（HTTP 404 + `{code:50001, message:"xx不存在", traceId}`），证明路径已注册且业务门禁正确工作（P3-6.1 先例：业务 404 = 端点活 = 门禁真活证据）。
4. 全量逐端点明细（method/path/verdict/http/note）见同目录 `R179-P1-端点真活矩阵-20260923.json`（2273 行）。
