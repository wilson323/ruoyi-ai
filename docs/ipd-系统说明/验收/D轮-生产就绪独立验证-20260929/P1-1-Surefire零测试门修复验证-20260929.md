> 归属：D4 最终裁决 **P1-1（N-6）**，根因 = 根 pom surefire `<groups>${profiles.active}</groups>` tag 过滤 + 无 failIfNoTests。修复路 = **B 路**（IPD 模块 pom 显式覆盖，D4 §7.2 原文修法）。

## 2. 现查事实：tag 统计与 D2 判据的口径差异（登记）

现查（2026-09-29，`src/test/java` 下逐文件比对）：含 `@Test` 文件 **383** 个、带 `@Tag` 文件 **386** 个、`@Tag("dev")` 出现 **436** 处；**未带 @Tag 的 @Test 文件 = 0**（comm 交集为空）。

即 D2「2987 个 @Test 无一带 tag」与当前磁盘现态**不符**——该判据或是历史快照、或按 @Test 方法数另一口径统计。按「事实优先/五必现查」规约以现态为准处理，但陷阱本身仍然活：

1. **对未来**：新增测试一旦忘加 `@Tag("dev")`，在根 pom groups=dev 过滤下会被静默跳过、假绿（D2 判据描述的机制真实存在）；
2. **对 profile**：切 `-P prod` 或 `-Dprofiles.active=<其他tag>` 时全部测试静默跳过、假绿（本轮精确复现）。

因此门禁修复照做，且两件套分别覆盖上述两个方向（清空 groups 断根 + failIfNoTests 兜底）。

## 3. 修复内容（1 文件：`ruoyi-modules/ruoyi-ipd/pom.xml`）

在模块 `build/plugins` 增加 `maven-surefire-plugin` 覆盖（D4 §7.2 P1-1 原文修法）：

```xml
<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-surefire-plugin</artifactId>
    <configuration>
        <groups combine.self="override"/>   <!-- ① 清空根 pom 的 ${profiles.active} tag 过滤 -->
        <failIfNoTests>true</failIfNoTests> <!-- ② 零测试门：0 测试执行直接转红 -->
    </configuration>
</plugin>
```

- 覆盖仅落 **ruoyi-ipd 模块**，不波及无测试的兄弟模块（failIfNoTests 会让它们整建制转红）；
- `combine.self="override"` 保证根 pom 的 `<groups>${profiles.active}</groups>` 被整体替换而非合并；
- 根 pom 零改动（框架/兄弟模块行为零变化）。

## 4. 验证证据（2026-09-29 实跑，单模块错峰、无 `-am`/`clean`）

三证：

1. **假绿复现（修复前）**：`-Dtest=IpdPageParamGuardTest -Dprofiles.active=nothing` → `Tests run: 0, Failures: 0, Errors: 0, Skipped: 0` + `BUILD SUCCESS`（10:13 实跑）——P1-1 向量成立；
2. **同命令转真跑（修复后）**：同上命令 → `Running org.ruoyi.ipd.security.IpdPageParamGuardTest / Tests run: 10 ... BUILD SUCCESS`（10:14 实跑）——groups 过滤确已清空（若未清空，`profiles.active=nothing` 会把 10 例全部滤掉）；
3. **零测试门自证能红**：`-Dtest=NoSuchTestClassExists -Dsurefire.failIfNoSpecifiedTests=false` → `BUILD FAILURE: No tests were executed! (Set -DfailIfNoTests=false to ignore this error.)`（10:14 实跑）——门在 0 测试时确实会红，非恒绿；
4. **回归**：`-Dtest='IpdPageParamGuardTest,Contract01MethodNotAllowedEnvelopeTest,IpdNotFoundBaselineParityTest,IpdWebSecurityConfigTest,Qa07ErrorContractAcceptanceTest,P073BehaviorAcceptanceTest'` → **Tests run: 33, Failures: 0, Errors: 0, Skipped: 0 BUILD SUCCESS**（10:14 实跑）。

## 5. 语义决策与残留

- **模块级而非根级**：failIfNoTests=true 只落 ruoyi-ipd。根 pom 清 groups 会影响所有模块（含大量无测试模块）的构建形态，超出 P1-1 修复范围；兄弟模块要收口须各自挂卡。
- **`@Tag("dev")` 约定保留**：清空 groups 后 tag 不再影响执行（excludedGroups=exclude 语义由根 pom 继承不变，`@Tag("exclude")` 仍可显式排除）；现有 383 个测试文件的 @Tag 标注无害，不回改。
- **CLI `-Dgroups=` 逃生口**：显式命令行注入仍可能重新引入 tag 过滤（Maven 用户属性 vs 显式 POM 配置的优先级差异），但一旦过滤结果为 0 测试，failIfNoTests 会转红兜底——静默假绿路径已封死。
- **残留**：兄弟模块（ruoyi-chat / ruoyi-system 等）仍继承根 pom groups 过滤，0-test 假绿面仍在——需各自模块收口（本轮范围外，待挂卡）。
