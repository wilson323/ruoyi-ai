## 当前事实与全链路反思

| 链路 | 当前源码证据 | 判断 |
| --- | --- | --- |
| 创建与执行 | `ProjectAgentController#create` → `ProjectAgentRunService#create` → `ProjectAgentRunExecutor` → `AgentScopeProjectAgentKernel#execute` | 保留唯一业务运行口。SSE 不能再次调用 agent 或创建 run。 |
| 旧事件转换 | Kernel 内 `EventBridge` 手工映射文本、工具开始／结果、模型步骤 | 不能因已使用 AgentScope Model 就认定官方 AG-UI 已接入。原映射缺工具参数、子事件、状态、官方 interrupt 等。 |

| 前端工具及多模态 | 本切片未实现官方前端工具挂起结果桥接，当前创建输入仍为 message 文本 | 不冒充已支持；必须校验本次授权工具／schema，并核官方版本支持范围（文档类型本就不支持）。 |

## 版本与官方 API 实证

当前项目父 POM 在核查时声明 `agentscope.version=2.0.3`。实际本地 2.0.3 JAR 已用 JDK17 `javap` 核对：

- `AgentEventConverterRegistry#convert(AgentEvent, AguiStreamContext)` 可公开调用，直接挂在现有唯一后台订阅，无须建立另一条 agent loop。
- `AguiAgentAdapter#run(input[, RuntimeContext])` 没有直接接入既有 Flux 的公开转换方法。
- `AguiEventEncoder#encodeToJson` 可输出官方事件线格式。
- `HarnessAgent#streamEvents(List<Msg>, RuntimeContext)` 和 `AguiMessageConverter#toMsgList(RunAgentInput, Map<String, Interrupt>)` 实际存在，可供同线程恢复接线；本切片尚未将其接入正式恢复。
- 2.0.3 `ConfirmResult` 没有当前链接所述 reason 字段接口；完全覆盖最新链接还需核对升级候选，不能声称旧版本已有。
- registry 三参数构造的最后参数是子事件原生映射开关，不能误接时间戳开关。
- 2.0.3 与本机参考源码有 API 差异；例如工具合并枚举与 RuntimeContext 配置已变化。升级必须重新编译和验证，不能直接复制参考仓接口。
- 官方 starter 设置断开不 interrupt 也不会重放断线期间事件，因此需要保留业务持久日志。本次没有采用 starter 内存状态替代原 store。
