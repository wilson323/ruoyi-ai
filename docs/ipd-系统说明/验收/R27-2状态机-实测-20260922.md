## 8. 风险与后续

### 8.1 已识别风险

1. **路径模糊(回归 #1)**:`GET /api/v1/negative-feedbacks` 与 `/{id}` 的 path collision 是 pre-existing,
   不在本任务修复范围。建议后续在 controller 加 `@GetMapping("")` 显式空 path 或调整 path variable 顺序。

2. **`myInitiated` 占位卡语义**:当前实现按 count 数展开为占位 MyInitiatedTask,前端拿到 N 条同类型卡后聚合显示;
   若需精确单据视图(每条卡显示真实 sourceId/title),可改 `selectCount` → `selectList` 后逐条映射。

3. **`myPendingApprovals` 未做 leader_id 过滤**:当前实现查所有 LEADER_REVIEW/ADMIN_REVIEW 记录,不校验当前人是否就是 leader_id。
   真实审批场景应在 SQL 层加 `eq(leader_id, personId)` 过滤;本轮按"超级管理员查看全局"语义实现。

### 8.2 后续接力

- R177-A1 (UI) 可消费 `MyInitiatedTask` JSON,渲染「我发起的 / 待我审批」两个分组
- P0-6 可补充 stage_actions 表的聚合(目前仅覆盖 3 张业务单据)
