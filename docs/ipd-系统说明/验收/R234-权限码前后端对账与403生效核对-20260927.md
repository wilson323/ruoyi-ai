## 3. 403 生效通路验证结论

### 3.1 通路全景（实读异常处理器）

`@SaCheckPermission`（Sa-Token 注解鉴权）拒绝 → 抛 `cn.dev33.satoken.exception.NotPermissionException`
→ `IpdPermissionExceptionHandler.notPermission()`：

- `IpdPermissionExceptionHandler.java:23-24`：`@Order(Ordered.HIGHEST_PRECEDENCE)` +
  `@RestControllerAdvice(basePackages = "org.ruoyi.ipd.controller")`——优先于基线 SaToken/Global
  advice，且 basePackages 全覆盖（`PermissionAdviceCoverageTest` 防漂移，注释 :20-21），新增 controller 不会漏走 IPD 包络。
