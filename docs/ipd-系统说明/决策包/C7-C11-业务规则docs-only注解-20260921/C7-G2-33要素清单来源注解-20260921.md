## 3. docs-only 注解正文

1. **清单权威源声明**：33 要素清单的权威源是 `DOC-05.md §3 评审要素与硬否决（"G2-6 放行"行）` + `DOC-05.md §5 验证证据`（181 项检查通过、33 要素、14 否决）。任何代码、seed、运行时枚举均需以该表为比对基准。

3. **清单变更审批路径**：未来若 G3/P10/G4 阶段增减要素或否决项，须先在 `DOC-05.md §3 表` 增删行，再由 owner 拍板"减/加/移位"，最后落 `verify_contract.py` 重跑——非工程子任务可改清单。
