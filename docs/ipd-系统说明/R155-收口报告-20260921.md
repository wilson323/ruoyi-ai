## R155-F 契约脚本 PREFIX bug 修 ✅

### 真因
`scripts/check-ipd-contract.mjs` L83 给前端 path 无端加 PREFIX。前端 `ipdGet` / `ipdPost` 调用已含 `/api/v1/...`（`http.ts` 不做 PREFIX 拼接），脚本再加一次产出 `/api/v1/api/v1/recovery/check-90d` 双前缀假阳性。

### 改动
1 处删除 + 5 处注释（行 83/84/85/91/92）：
```js
// 旧
const key = `${c.verb} ${norm(PREFIX + c.path)}`;
// 新
const key = `${c.verb} ${norm(c.path)}`;
```
gapSet 仍走 `norm(PREFIX + g.path)`（known-gaps 路径是后端控制器注解，不含 PREFIX）→ 对齐 backendSet。

### 修后效果

|---|---|
| `POST /api/v1/api/v1/recovery/check-90d`（假阳性）| `POST /api/v1/recovery/check-90d`（真缺）|
| `GET /api/v1/api/v1/recovery/warnings`（假阳性）| `GET /api/v1/recovery/warnings`（真缺）|
