# 内置默认向量（embedding）模型（2026-09-30）

用户指令：向量模型地址默认 `http://171.43.138.237:9997/v1/embeddings`，模型名称 `Qwen3-Embedding-0.6B`，密码为空，作为内置写死。

## 取值与 URL 对应

| 项 | 值 | 说明 |
|---|---|---|
| base URL | `http://171.43.138.237:9997/v1` | Langchain4j `OpenAiEmbeddingModel` 固定拼 `POST {base}/embeddings`，拼后即用户原文；存全路径会拼成 `/v1/embeddings/embeddings`（实测 404） |
| 模型名 | `Qwen3-Embedding-0.6B` | 亦是 `ai_doc_embeddings.embed_model` 向量空间锚 |
| 密钥 | 无 | IPD 侧传空串（与 `decryptApiKey` 对无密文返回空串一致）；平台 `chat_model.api_key` 为 NULL（不发 Authorization 头） |
| 维度 | 1024 | 2026-09-30 curl 实测 |

## 两条链路各自的落点

- **IPD 文档 RAG**（`AiDocEmbeddingService.embedAsync / retrieveContext`）：读生效 `ai_model_configs` 行 `config_json.embedEndpoint/embedModel`。
  - 两键齐全 → 管理员配置（apiKey 复用该行密文），source=`ai_model_configs`；
  - 两键全缺或无生效配置 → 内置默认 `org.ruoyi.ipd.service.ai.BuiltinEmbeddingModel`（Java 唯一定义点），source=`builtin-default`，首次生效打一条 INFO；**不复用 chat 厂商密钥**；
  - 只填一键 → 视为配置不完整，RAG 关闭并 WARN；
  - 运维关闭：`ipd.ai.builtin-embedding.enabled=false`（此时无管理员配置即 RAG 关闭）。
- **平台知识库 RAG**（ruoyi-chat `EmbeddingModelFactory`）：按 `chat_model.model_name` 读取 `category='vector'` 行。安装种子 `docs/script/sql/update/2026-09-30-ipd-builtin-embedding-model-seed.sql` 缺则插入、已存在不覆盖。

## 为什么种子不写 `ai_model_configs`

该表每行是一套 chat 配置、没有用途列，embedding 只是生效行 `config_json` 的子键。插入一条 embedding 行会混进页48 chat 列表，被启用后对话会路由到向量模型；给现有行补子键属于 UPDATE，会覆盖管理员配置。所以 IPD 侧采用代码层内置默认。

## 防漂移

`BuiltinEmbeddingModelTest` 校验种子 SQL 与 Java 常量一致（模型名、维度、base URL、`api_key=NULL`、幂等、无 UPDATE/DELETE/ai_model_configs）。

## 风险

- 明文 HTTP、公网 IP、无鉴权：文档切片原文会经公网发往该端点；私有部署若禁止出网，置 `ipd.ai.builtin-embedding.enabled=false` 并在页48配置内网端点。
- 管理员若在生效 chat 行填 embed 两键，apiKey 会复用该行 chat 密钥发往 embed 端点（既有行为，本次未改）。
