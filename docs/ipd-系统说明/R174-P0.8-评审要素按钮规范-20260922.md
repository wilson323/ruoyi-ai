## 1. 业务逻辑（BR-IPD-06 + 页47 + AC-GATE）

### 1.1 评审要素本质

- **作用**：定义 5 大 Gate（G1..G5）的判定标准；每个 Gate 33 项要素，14 项为否决位
- **生命周期三态**：draft（新建即草稿）→ published（发布生效）→ archived（归档保留）
- **激活态**：enabled='1' 时出现在 Gate 评审清单；'0' 时退出清单但保留历史判定引用（禁删：G-02 证据链）
- **业务约束**：定义字段（elementName/passStandard/isVeto/sortOrder/vetoDualRequired/thresholdJson）已发布后**冻结**；改定义须 copy 出新草稿再发布

### 1.2 业务流转图

```
                ┌─copy/duplicate─┐                    ┌──restore──┐
                ↓                │                    ↑            │
   [外部] → (draft) ──publish──→ (published) ──archive──→ (archived)
                │       ↑                                    │
                │   (新草稿)                                 │
                ↓                                            │
            (draft 改定义) ←────────────revert──── (audit log)
                                 (DRAFT 限定)

   enabled 开关：draft/published 任意时刻可 disable → enabled='0'（从业务清单消失）
                published disable 后可 update(enabled='1') 重新启用
                draft 状态启停无意义（业务不可见），后端 409 拦截
```

### 1.3 业务规则红线（AC-GATE + BR-IPD）

| 规则 | 内容 | 触犯时 |
|---|---|---|
| BR-IPD-06 | 33 项要素 / 14 否决位为种子目标值 | 实际超出不报错（柔性） |
| AC-GATE-1a~d | 否决项判定不通过阻断 Gate 提交 | 业务侧强制，后端不重复校验 |
| G-02 | 评审要素禁物理删除 | 后端无 delete 接口，禁字面量 |
| G-06 | 不造数 | 前端禁 mock 要素数据 |
| AC-GATE-15/19/20 | 否决阻断 + 要素定义快照冻结 + 评审材料 + 会议纪要 | submit 时全要素已判 + 否决 0 + 材料 1 + 纪要 1 |

## 2. 代码逻辑（后端）

### 2.1 状态机枚举

```java
// GateElementService
public static final String STATUS_DRAFT     = "draft";
public static final String STATUS_PUBLISHED = "published";
public static final String STATUS_ARCHIVED  = "archived";
```

| 状态 | enabled 默认 | 业务清单可见 | 是否可编辑定义 | 是否可启停 | 是否可恢复 |
|---|---|---|---|---|---|
| draft | '0'（强制） | ❌ | ✅ | ❌ 409（先 publish） | ❌ 409 |
| published | '1'（发布时置） | ✅ | ❌ 409（仅 enabled 可改） | ✅ | ❌ 409 |
| archived | '0'（归档时置） | ❌ | ❌ 409（archived 不可编辑） | ❌ 409 | ✅ restore |

### 2.2 后端 11 admin endpoint（`/api/v1/gate-elements`）

| # | Method | Path | 权限码 | Actor 守卫 | 业务效果 |
|---|---|---|---|---|---|
| 1 | GET | `/` | List | requireInternal | 仅 enabled='1' 启用要素 |
| 2 | GET | `/manage` | List | **requireAdmin** | 全生命周期（含 draft/archived） |
| 3 | POST | `/` | Create | requireAdmin | 新建即 draft，enabled 强制 '0' |
| 4 | POST | `/{id}/update` | Update | requireAdmin | 草稿改定义；已发布仅改 enabled；归档 409 |
| 5 | POST | `/{id}/disable` | Disable | requireAdmin | enabled→'0'；archived 409 |
| 6 | POST | `/{id}/publish` | Publish | requireAdmin | draft→published，enabled→'1'，version++ |
| 7 | POST | `/{id}/archive` | Archive | requireAdmin | draft/published→archived，enabled→'0' |
| 8 | POST | `/{id}/copy` | Copy | requireAdmin | 任意状态克隆为新 draft（新编码） |
| 9 | POST | `/{id}/duplicate` | Copy（共用） | requireAdmin | 任意状态克隆为新 draft（自动 -DUP 编码） |
| 10 | POST | `/{id}/revert` | Revert | requireAdmin | DRAFT 限定：从审计快照恢复字段 |
| 11 | POST | `/{id}/restore` | Restore | requireAdmin | archived→draft，version 保留 |

**Copy 与 Duplicate 的区别**（业务语义）：
- `copy/{id}`：用户显式指定新编码（`?newElementCode=...`），用于精确克隆
- `duplicate/{id}`：后端自动生成 `-DUP` / `-DUP2` / ... 编码 + 「（副本）」名称；用于快速克隆同一模板

两者共用 `OPERATION_GATE_ELEMENT_COPY` 权限码（前端的「复制」按钮默认走 `duplicate`，精确克隆走 `copy` 弹窗）。

### 2.3 后端 5 business endpoint（`/api/v1/gates/{gateId}/...`）

| # | Method | Path | 守卫 | 业务效果 |
|---|---|---|---|---|
| B1 | GET | `/elements` | requireInternal | 33 要素按 Gate 展示（含否决标记 + 当前判定） |
| B2 | POST | `/element-results` | requireInternal | 逐项判定（PASS/CONDITIONAL/FAIL） |
| B3 | POST | `/submit` | requireInternal | 提交评审（全要素已判 + 否决 0 + 材料 1 + 纪要 1） |
| B4 | GET | `/legacy` | requireInternal | 条件遗留清单（AC-GATE-17 防线） |
| B5 | POST | `/element-results/{resultId}/close` | requireInternal | 关闭遗留（责任人/超管，凭证必填） |

业务级按钮**不在评审要素管理后台**，由 `views/ipd/project/gate-review/` 页面承载。

## 3. 前端规范（核心：按钮显示矩阵）

### 3.1 单一权威源：状态 → 按钮决策函数

**禁止**在模板里写 `v-if="row.status === 'draft'"` 这种散落判断。统一封装为：

```typescript
// apps/web-antd/src/views/ipd/admin/gate-elements/button-policy.ts
import type { IpdGateElement } from '../../../../api/ipd/gate-element';

export type GateElementStatus = 'draft' | 'published' | 'archived';

interface ButtonDecision {
  visible: boolean;
  enabled: boolean;
  /** 后端拒绝时给前端的预期 code（用于禁用后 hover 提示） */
  rejectCode?: string;
}

/**
 * 按钮显示策略（state × permission × role 三维决策的单一权威源）。
 *
 * 规则：
 * - draft: 编辑=✅，启停=❌409（先 publish），发布=✅，归档=✅，复制=✅，副本=✅，回滚=✅，恢复=❌409
 * - published: 编辑=仅 enabled 字段，启停=✅，发布=❌409，归档=✅，复制=✅，副本=✅，回滚=❌409，回复=❌409
 * - archived: 编辑=❌409，启停=❌409，发布=❌409，归档=❌409，复制=✅（唯一克隆路径），副本=✅，回滚=❌409，恢复=✅
 *
 * 注：禁用态(disabled/已 enabled='0' 但状态非 archived)可走 update(enabled='1') 重新启用 — 后端允许。
 */
export function decideEditBtn(row: IpdGateElement): ButtonDecision {
  if (row.status === 'archived') return { visible: true, enabled: false, rejectCode: 'STATE_CONFLICT' };
  // published 仍可编辑（仅 enabled 字段）；前端不禁用，但提交时校验
  return { visible: true, enabled: true };
}

export function decideDisableBtn(row: IpdGateElement): ButtonDecision {
  if (row.status === 'archived') return { visible: false, enabled: false, rejectCode: 'STATE_CONFLICT' };
  if (row.enabled === '0') return { visible: false, enabled: false }; // 已停用，显示「启用」反向按钮
  return { visible: true, enabled: true };
}

export function decideEnableBtn(row: IpdGateElement): ButtonDecision {
  if (row.status === 'archived') return { visible: false, enabled: false };
  if (row.status === 'draft') return { visible: false, enabled: false, rejectCode: 'STATE_CONFLICT' };
  if (row.enabled === '1') return { visible: false, enabled: false }; // 已启用，不显示
  return { visible: true, enabled: true };
}

export function decidePublishBtn(row: IpdGateElement): ButtonDecision {
  return row.status === 'draft'
    ? { visible: true, enabled: true }
    : { visible: true, enabled: false, rejectCode: 'STATE_CONFLICT' };
}

export function decideArchiveBtn(row: IpdGateElement): ButtonDecision {
  return row.status === 'archived'
    ? { visible: false, enabled: false }
    : { visible: true, enabled: true };
}

export function decideCopyBtn(row: IpdGateElement): ButtonDecision {
  // copy/duplicate 任意状态可执行（唯一克隆路径在 archived）
  return { visible: true, enabled: true };
}

export function decideDuplicateBtn(row: IpdGateElement): ButtonDecision {
  return { visible: true, enabled: true };
}

export function decideRevertBtn(row: IpdGateElement): ButtonDecision {
  return row.status === 'draft'
    ? { visible: true, enabled: true }
    : { visible: true, enabled: false, rejectCode: 'STATE_CONFLICT' };
}

export function decideRestoreBtn(row: IpdGateElement): ButtonDecision {
  return row.status === 'archived'
    ? { visible: true, enabled: true }
    : { visible: true, enabled: false, rejectCode: 'STATE_CONFLICT' };
}
```

### 3.2 完整按钮显示矩阵（11 行 × 9 按钮列）

✅ = 按钮可见且启用；⚪ = 按钮可见但禁用（hover 提示 rejectCode）；✗ = 按钮不可见

| 状态 \ 按钮 | 编辑 | 停用 | 启用 | 发布 | 归档 | 复制 | 副本 | 回滚 | 恢复 |
|---|---|---|---|---|---|---|---|---|---|
| **draft** | ✅ | ⚪ 409（先 publish） | ✗ | ✅ | ✅ | ✅ | ✅ | ✅ | ⚪ 409 |
| **published + enabled='1'** | ✅ | ✅ | ✗ | ⚪ 409 | ✅ | ✅ | ✅ | ⚪ 409 | ⚪ 409 |
| **published + enabled='0'**（已停用） | ✅（仅 enabled 字段） | ✗ | ✅ | ⚪ 409 | ✅ | ✅ | ✅ | ⚪ 409 | ⚪ 409 |
| **archived** | ⚪ 409 | ✗ | ✗ | ⚪ 409 | ✗ | ✅ | ✅ | ⚪ 409 | ✅ |

### 3.4 缺失的 API exports（`api/ipd/gate-element.ts` 补全）

```typescript
// 补全 §3 中新增按钮的 API 调用

/** 管理视图列表（含 draft/archived/disabled 全生命周期；仅超管后台使用） */
export async function listGateElementsForManage(gate?: string): Promise<IpdGateElement[]> {
  const data = await ipdGet<unknown[]>('/gate-elements/manage', gate ? { gate } : undefined);
  return Array.isArray(data) ? data.map(normalize) : [];
}

/** 发布草稿到 published（递增 version） */
export function publishGateElement(id: string): Promise<IpdGateElement> {
  return ipdPost<unknown>(`/gate-elements/${id}/publish`, {}).then(normalize);
}

/** 归档已发布或草稿（终态） */
export function archiveGateElement(id: string): Promise<IpdGateElement> {
  return ipdPost<unknown>(`/gate-elements/${id}/archive`, {}).then(normalize);
}

/** 复制（精确编码） */
export function copyGateElement(id: string, newElementCode: string): Promise<IpdGateElement> {
  return ipdPost<unknown>(`/gate-elements/${id}/copy?newElementCode=${encodeURIComponent(newElementCode)}`, {}).then(normalize);
}

/** 副本（自动 -DUP 编码 + 「（副本）」名称） */
export function duplicateGateElement(id: string): Promise<IpdGateElement> {
  return ipdPost<unknown>(`/gate-elements/${id}/duplicate`, {}).then(normalize);
}

/** 回滚到指定审计快照（DRAFT 限定） */
export function revertGateElement(id: string, auditLogId: string): Promise<IpdGateElement> {
  return ipdPost<unknown>(`/gate-elements/${id}/revert?auditLogId=${auditLogId}`, {}).then(normalize);
}

/** 归档恢复（archived → draft） */
export function restoreGateElement(id: string): Promise<IpdGateElement> {
  return ipdPost<unknown>(`/gate-elements/${id}/restore`, {}).then(normalize);
}

/** 启用（disabled 状态 update enabled='1'） */
export function enableGateElement(id: string): Promise<IpdGateElement> {
  return ipdPost<unknown>(`/gate-elements/${id}/update`, { enabled: '1' }).then(normalize);
}
```

### 3.5 管理视图入口（`/manage` endpoint）

**当前问题**：admin 后台调用 `/gate-elements` 走 `listByGate`（仅 enabled='1'），导致 draft/archived 不可见，无法在管理界面看到全生命周期。

- 在管理后台头部增加一个开关：「显示全生命周期」/「仅显示启用」

import { describe, expect, it } from 'vitest';
import {
  decideEditBtn, decidePublishBtn, decideArchiveBtn,
  decideRevertBtn, decideRestoreBtn, decideEnableBtn, decideDisableBtn,

const row = (overrides: Partial<IpdGateElement>): IpdGateElement => ({

describe('button policy matrix', () => {

    expect(decideDisableBtn(r).visible).toBe(false);
    expect(decideRestoreBtn(r).enabled).toBe(true);
    expect(decidePublishBtn(r).enabled).toBe(false);
  });
