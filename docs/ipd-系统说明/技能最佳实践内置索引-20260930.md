## 2. 用法原则

- 方法改写为 IPD **步骤 / 输入 / 输出 / 禁止**；文末一行依据。
- 已有技能只**补原文件**，目录名=`name`=`ipd-action` 绑定不变。
- 通用网页生成器 / 通用原型工具：**不**新建运行时技能；有用步骤写入 P01 / L03。
- 轻管「仅登记完成」且来源无步骤：**跳过**。

## 6. 为何不建第二套 MCP / 技能运行时

1. IPD 执行面已由 `ipd-skills` + 动作码加载，再挂一套 MCP/技能根会造成双轨与映射漂移。
2. 上游（pm-skills / prd-html / QoderWork）是**方法源**，版权与演进在外部；本仓只保留动作化步骤摘要。
3. 联网深度研究、Notion/Figma 连接器与 IPD「仅本项目资料」红线冲突，故只吸收可离线改写的流程门禁。
4. `capability-packs.json` / 动作映射本轮冻结，避免未授权接线。
