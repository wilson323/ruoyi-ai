## 七、本轮新发现的根因教训（R172 沉淀）

### 教训 1: vite 后台化铁律（memory 1e1172bb 复盘确认）

**根因**：vite 前台读 stdin，nohup / `&` 后台化缺活 pty → event loop 锁死 → LISTEN 端口 OK 但 HTTP 全超时。

**正确起法**（已沉淀为本仓启 vite 红线）：
```bash
# 错误（卡死）：
nohup node vite.js --config ... > log 2>&1 &

# 正确（活 pty）：
cd apps/web-antd && exec node node_modules/vite/bin/vite.js --port 15666 --host 127.0.0.1
# 配合 Bash is_background=true + GetTerminalOutput
```

**症状指纹**：终端出现 `VITE v7.2.7 ready`（进程活着）+ `lsof -i :15666` 显示 LISTEN + 但 `curl` 5s/10s HTTP 000 超时 → 100% 是 nohup 卡死。

**实测 3 次确认**：
1. 第一次：`nohup ... &` → 卡死
2. 第二次：换 15688 端口重起 `nohup` → 仍卡死
3. 第三次：活 pty 起法 → HTTP 200 in 23ms

### 教训 2: vite cwd 必须在 apps/web-antd 子目录

**根因**：`vite.config.mts` 在 `apps/web-antd/vite.config.mts`，相对路径解析依赖 cwd。仓根起 vite → inject-metadata 插件报 "Cannot find matching package.json"。

**正确起法**：先 `cd /Users/mac/Documents/ruoyi-ipd-web/apps/web-antd` 再启 vite。

### 教训 3: vite 二进制在仓根 node_modules

vite 装在 `/Users/mac/Documents/ruoyi-ipd-web/node_modules/vite/bin/vite.js`（不是 `apps/web-antd/node_modules`），要从仓根用绝对路径调。
