## 全局铁律（贯穿 5 阶段）

1. **不跳任何验证**——即使是 live test 也要跑过
2. **不 mock 冒充**——单测 mock 不算真活，必须真库真接口
3. **不假绿翻卡**——看板汇总卡子卡未完成不翻 done
4. **不擅自 commit**——每个 commit 必须有真实证据
5. **不漂移 scope**——发现新问题登记到阻塞清单，不私自扩大
6. **三证齐发**——每个功能必须 HTTP + DB + 截图三证齐全
7. **commit 对账**——commit 后 `git show --stat HEAD` 对照 message
8. **看板同步**——每阶段完成立即更新看板卡 + 证据注记
