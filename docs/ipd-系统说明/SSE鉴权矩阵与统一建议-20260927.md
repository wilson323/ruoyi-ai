## 3. 风险判定

1. **无数据面匿名泄漏**（现网 9 端点均有有效校验或副作用面为零）——但 #1/#3/#4/#5 四端点鉴权完全依赖"白名单 + 方法内手写检查"，未来新增端点忘写检查即静默裸奔，属**结构性风险**。
2. **#5 权限码缺口**：`/chat`（同步）要 `@SaCheckPermission(OPERATION_AI_COPILOT)`，`/chat/stream` 仅 `requireInternal()`——同能力双口径，stream 可绕行权限码。
3. **#4 URL token 暴露面**：JWT 进 query → Nginx access log / 浏览器历史 / Referer；且走 `/api/v1/**` 白名单跳过拦截器 clientid 绑定校验（SecurityConfig L72-80），token 被窃取时无第二因子。
4. **通道 2b 跨会话混用**：aiflow 流用主站 token，IPD 会话页触发时空 token 直达无兜底。
5. **失败语义三口径分裂**：HTTP 401（#1/#4）/ 流内 error 帧（#3/#5，2026-09-11 MIME 修复所致）/ 拦截器 NotLogin 全局异常（#6-9）。
6. **门禁盲区**：`scripts/check-sse-contract.sh` 仅做 controller 计数与响应契约，不扫鉴权注解矩阵。

## 4. 统一口径建议（全部待 owner 拍板，未实施）
