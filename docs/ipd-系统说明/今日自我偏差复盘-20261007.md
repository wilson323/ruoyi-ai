# 今日会话自我偏差复盘（2026-10-07）

> 这份文档不是又一份盘点报告。它记录的是**我自己在本会话内实际犯的 6 次偏差**，
> 以及为什么「明知这些模式、且刚把它们写进纪律」之后仍然照犯。
> 样本 = 本会话约 4.5 小时、145+20 个历史会话的交叉分析、3 个脚本的实跑与变异验证。

## 二、根因不是「忘了」，是三个结构

### R1 代价不对称 —— 读代码永远比读规则便宜

我修正 #4 花了两轮往返（先跑 22 条测试发现崩、再写 spy 脚本打印中间值）。
而当初写那行 sed 只花了几秒。**验证的成本是真的，但不验证的成本是隐形的**——
没人会告诉我「这行 sed 昨天把守卫弄成永放行了」。

这就是为什么 67 条纪律拦不住：纪律提高的是违规成本，而违规的真实成本是**延迟暴露**。

### R2 长上下文稀释 —— 今天 4.5 小时 = 本仓史上最长的会话之一

我在 03:47 写下「结论纪律今天写、当天又犯」的诊断。
然后在 04:38（不到一小时后）犯了 #6。

**这不是讽刺，是证据。** 我能在报告里精确诊断这个机制，同时在自己的第 4.5 小时里被它命中。
规则文本在上下文最前面，而我在第 N 轮推理时，注意力早已被当前任务占满。

**推论：任何依赖「记住规则」来生效的机制，在长会话里必然衰减到接近零。**

### R3 治理覆盖错位 —— 机制建在错误的位置

我今天的两次「差点出事」都不是因为没写规则，而是：

- **#4**：守卫只防「写坏文件」，不防「脚本自己静默出错」。sed 报错了，管道退出码还是 0，
  脚本继续跑完并报告成功。**没有一层检查「这一步的工具调用是否真的产生了预期形状的输出」。**
- **repowise**：`repowise status` 报 `1/1 repos indexed`，实测 `Files=0`。**工具自己给自己发了绿牌。**

**R3 的本质：现有机制全部是「事后检查产出物」，没有一条是「产出物形状不合法时拿不出手」。**

## 三、为什么「写报告」这个动作本身解决不了问题

我今天写了一份 500 行的报告，结论是「不要再写新纪律了」。
**如果这份报告本身也算一份纪律，那我今天就又犯了一次。**

区别只在于：它有没有**降低验证成本**。逐条对照我给的 5 个方案——

| 方案 | 降低验证成本？ | 命运 |
|---|---|---|
| A. 数字必须带仪器自检输出 | ✅ 是——不跑就没法交付 | 已作为建议给出 |
| B. Stop 钩子做数字出口检查 | ✅ 是——不检查拿不出回复 | 已作为建议给出 |
| C. 长会话强制插入 | ❌ 否，只是提醒 | 建议里已标为 P1 |
| D. 记忆库标签统一 | ✅ 是（可检索） | 已部分落地（本次新记忆都加了 description） |
| E. 报告标时效三元组 | ❌ 否，只是提醒 | P2 |

**本会话唯一真正落地的 A 类动作，是我给守卫写的 22 条测试集 + 3 种变异自证。**
那是我今天唯一一次「改完之后能确信它是对的」的体验——因为我能跑它、能看它变红。
而其余所有「我写下了正确的结论」的时刻，都没有这种确定性。

## 四、根除：三条，按「能否被机器强制」排序

### 根除 1（P0）：工具调用的产出必须自证形状，否则不进上下文

**今天 #4 的死法**：`sed` 失败 → 空串 → `grep` 失配 → 退出 0。整条链路**每一步都合法**，只有合起来是错的。

可行的强制点：**PostToolUse 钩子已经能看见每次工具调用的输出。**
给它加一条判据——凡是脚本类调用，检查其输出是否符合预期形状（非空、有内容行数、退出码语义匹配）。
形状不对就在下一轮开始前注入一行「上一步 X 的输出形状异常」。

**这把验证从「AI 决定要不要验」变成「环境强制告知」。** 这是唯一能穿过 R1 的位置。

### 根除 2（P0）：让结论里的数字与其证据**物理绑定**

不是「要求附证据」（这是纪律），而是**让证据成为数字的一部分**。
例：报「22/22 全绿」时，测试脚本直接把结果写成可被下游引用的产物文件；
报「6403 文件」时，命令本身输出结构化 JSON 而不是表格。

**判据**：把证据删掉，数字应当无法单独被引用。做不到就是没改到。

### 根除 3（P1）：长会话的强制复检点

R2 无法靠自律解决。唯一有效的是**环境强制**：
每 N 轮（或每次 Stop）自动跑一次只读自检（当前工作树状态、工具链连通性、git 与远端关系），
结果以固定格式注入。这样「上下文稀释」就不再是问题——因为关键事实**每轮都新鲜**。

## 五、留给下一个人的一句话

今天最重要的一课不是那 6 个错，是这个：

**我在 03:47 精确诊断了「纪律写下来当天还会犯」，然后在 04:38 犯了第 6 次。**

如果连我这个能写出这份诊断的人，都无法靠阅读诊断来避免复发——
那么**任何依赖阅读的方案都是无效方案**。
唯一的出路是让错误**在结构上无法发生**，而不是在文档里被反复叮嘱。

这也是为什么本报告第 4.10 节那个 22 条测试集，比前面 400 行分析更有价值：
它是今天唯一一个我能跑它、能看它变红、能确信它是对的交付物。
