## 2. 自证能红门禁验证

**目的**：避免「假绿」陷阱——门禁脚本不能因永远不触发违规而误报绿。

**操作**：
```bash
# 1. 移走触发条件
mv docs/script/sql/update/2026-09-17-ipd-braud01-audit-grant-restrict.sql /tmp/braud01-bak.sql

# 2. 跑门禁（期望红）
bash scripts/ci/check-braud01-audit-grant.sh > /tmp/braud01.log 2>&1
echo "EXIT=$?"   # 实际 EXIT=1（红）

# 3. 加回触发条件
mv /tmp/braud01-bak.sql docs/script/sql/update/2026-09-17-ipd-braud01-audit-grant-restrict.sql

# 4. 再跑（期望绿）
bash scripts/ci/check-braud01-audit-grant.sh > /tmp/braud01.log 2>&1
echo "EXIT=$?"   # 实际 EXIT=0（绿）
```

**结果**：
- ✅ 移走 → EXIT=1（FAIL：「缺活语句: REVOKE INSERT...」+「缺活语句: REVOKE UPDATE, DELETE...」）
- ✅ 加回 → EXIT=0（OK：登记件齐全）

**反向证明**：脚本不是「假绿」——违规会被抓到。
